## 2. 已冻结的产品共识

### 2.1 品牌

- 主品牌：**见域**；
- 品牌口号：**看见更多观点，打开认知边界。**；
- 品牌组合：**见域｜看见更多观点，打开认知边界**。

### 2.2 产品定位

见域是一款面向个人的 AI Skills 思考与行动工作台。

它连接不同领域的人物视角、专业顾问、任务助手和工作方法，既帮助用户处理现实中的事情，也帮助用户从更多视角想清问题。

### 2.3 两类核心价值

1. **现实支持**：处理生活、学习和工作中的具体事情；
2. **思维拓展**：从不同领域、人物、立场和思维模型理解问题。

两类价值可以在同一个议题中双向切换，不是互斥入口或固定流程。

### 2.4 两种使用模式

1. **单 Skill 模式**：完成明确任务或持续咨询；
2. **多 Skill 模式**：协作处理复杂议题。

单 Skill 可以升级为多 Skill，多 Skill 也可以临时指定单个 Skill 回应，切换不丢失议题上下文。

### 2.5 核心产品关系

```text
问题
→ 一个或多个 Skills
→ 单 Skill 咨询 / 多 Skill 协作
→ 自由追问 / 分轮推进 / 专业工作流
→ 判断 / 行动方案 / 知识成果
```

## 4. 设计原则

### 4.1 问题优先，而不是技术术语优先

首页首先帮助用户表达实际问题，不要求用户理解 Agent、多智能体或工作流等技术概念。

### 4.2 Skill 是能力载体，不等于名人角色

人物视角、专业顾问、任务助手和工作流能力并列。真实人物型 Skill 必须明确 AI 模拟和来源边界。

### 4.3 议题是长期容器，不是强制表单

底层以议题组织内容，但用户可以直接提问，由系统自动建立议题；复杂用户也可以显式创建长期议题。

### 4.4 自由追问是一级操作

用户应始终能够补充背景、指定 Skill、质疑观点、改变方向和继续追问。

### 4.5 “下一轮”是结构化推进

“下一轮”不是简单重复所有角色发言，而是根据当前状态推进质疑、核查、比较、收敛或行动。

### 4.6 现实支持与思维拓展可交叉

分类用于发现、推荐和理解，不用于限制流程。同一议题可以在两类价值之间自然切换。

### 4.7 从建议走向行动与成果

见域不应止于展示对话。重要结论、行动、资料和成果需要可保存、更新和复盘。

### 4.8 视觉服务内容

建议的整体气质：

```text
70% 高级生产力工具
20% 智库编辑部
10% AI 动态反馈
```

避免满屏霓虹、复杂仪表盘和只靠头像堆叠表达多角色协作。

并行对话不得擅自改变以下已确认内容：

- 主品牌“见域”；
- 口号“看见更多观点，打开认知边界”；
- 两类核心价值：现实支持、思维拓展；
- 两类可以双向跨界；
- 两种使用模式：单 Skill、多 Skill；
- Skill 包含人物视角、专业顾问、任务助手和工作流能力；

- 自由追问与下一轮并存；
