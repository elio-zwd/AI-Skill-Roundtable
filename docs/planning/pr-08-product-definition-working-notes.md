## 4. 已确认的产品定义

> 见域是一款面向个人的 AI Skills 思考与行动工作台。
>
> 它连接来自不同领域的人物视角、专业顾问、任务助手和工作方法，为用户提供两类核心帮助：一类是处理生活、学习和工作中的现实问题，另一类是从不同视角重新理解问题、发现盲区并拓展思维边界。
>
> 用户可以选择一个 Skill 完成明确任务或持续咨询，也可以召集多个 Skills 共同分析复杂议题。通过自由追问、分轮协作和专业工作流，见域帮助用户将问题逐步转化为更清晰的判断、可执行的行动方案，以及能够长期保存和继续完善的知识成果。

简短解释：

> 见域连接不同领域的 AI Skills，既帮助你处理现实中的事情，也帮助你从更多视角想清问题。

内部产品原则：

> 单 Skill 解决具体问题，多 Skill 推进复杂议题。

## 5. 已确认的两类核心价值

### 5.1 现实支持

帮助用户处理生活、学习和工作中具体发生的事情，包括任务拆解、规划、沟通、研究、写作、整理、决策与成果交付。

面向用户的候选展示名称：**生活与工作**。

### 5.2 思维拓展

帮助用户引入不同领域、人物、立场和思维模型，重新理解问题、发现盲区、补充反方意见并拓展认知边界。

面向用户的候选展示名称：**思维与视角**。

### 5.3 跨界原则

两类价值不是互斥模式，也不是一次选择后固定不变的流程。

- 用户可能先使用“现实支持”Skill 解决具体任务，随后加入人物视角或反方 Skill 做思维拓展；
- 用户也可能先通过多个视角想清问题，随后加入规划、写作、核查或行动类 Skill 推进现实执行；
- 同一个 Skill 可以有一个主要价值类型，并同时拥有跨领域能力标签；
- 同一个持续议题可以在两类价值之间多次切换，不应被拆成互不关联的会话。

## 6. 已确认的两种使用模式

### 6.1 单 Skill 模式

适合边界明确的咨询或任务，例如考公规划、领导任务拆解、职场沟通、事实核查、人物视角请教。

### 6.2 多 Skill 模式

适合复杂决策、长期成长、复杂项目、跨领域研究和需要观点协作的议题。

### 6.3 模式切换原则

- 单 Skill 咨询可以随时邀请其他 Skills，升级为多 Skill 协作；
- 多 Skill 协作可以临时指定某一个 Skill 单独回应；
- 模式变化不应中断议题上下文、资料、结论和行动记录。

## 7. 已确认的产品对象关系

```text
用户的实际问题
→ 选择一个或多个 Skills
→ 单 Skill 咨询或多 Skill 协作
→ 持续追问 / 分轮推进 / 专业工作流
→ 判断、行动方案与知识成果
```

核心对象暂定：

- **问题**：用户开始使用见域的入口；
- **Skill**：人物视角、专业顾问、任务助手和工作流能力的统一载体；
- **议题**：持续承载背景、上下文、资料、咨询、协作、结论与行动的容器；
- **圆桌**：多 Skill 协作的主要形式，不再等同于整个产品；
- **轮次**：多 Skill 讨论的结构化推进单元；
- **成果**：判断、方案、行动项、知识笔记与可交付内容。

## 8. 已确认的交互原则

- 用户在同一议题内可以持续自由追问；
- “下一轮”与自由追问并存，是结构化推进方式，不是强制结束或重新开始；
- 产品底层以议题组织内容，但首页可以允许用户直接提问并自动建立议题；
- 用户可以显式创建长期议题并补充背景、约束、资料和期望成果；
- 用户可以在现实支持与思维拓展之间自然切换；
- 人物型 Skill 与专业顾问、任务助手、工作流能力并列，不作为唯一品牌中心。
