## 2. 正式产品定义

> 见域是一款面向个人的多智能体思考与行动工作台。用户围绕持续议题，调用人物视角、专业顾问、任务助手和工作流能力，通过自由追问与分阶段推进，沉淀判断、行动方案和知识成果。

简短说明：

> 见域连接不同领域的 AI Skills，既帮助用户处理现实中的事情，也帮助用户从更多视角想清问题并推进下一步行动。

核心产品关系：

```text
问题是入口
→ Skill 是能力载体
→ 单 Skill / 多 Skill 是使用模式
→ 议题持续承载背景、资料、过程与成果
→ 自由追问 / 阶段推进 / 专业工作流
→ 判断 / 行动方案 / 知识成果
```

## 3. 两类核心价值

### 3.1 现实支持

处理生活、学习和工作中的具体事情，例如任务拆解、规划、沟通、研究、写作、核查、决策和成果交付。

### 3.2 思维拓展

引入不同人物、领域、立场、反方意见和思维模型，帮助用户重新理解问题、发现盲区并拓展认知边界。

### 3.3 使用规则

- 正式名称保留“现实支持”“思维拓展”，并在 UI 中配通俗说明；
- 两类价值可跳过、单独选择或组合使用，不强制先选；
- 两类不是永久标签，也不会把同一议题拆成互不关联的两条线；
- 同一议题可在思维与行动方向之间多次切换。

## 4. 单 Skill 与多 Skill

- **单 Skill**：适合明确问题、垂直任务或持续咨询；
- **多 Skill**：适合复杂议题、重大决策、长期成长和跨领域协作；
- 单 Skill 可邀请其他 Skill，升级为多 Skill；
- 多 Skill 中点名某个 Skill 只是临时定向回答，不自动退出多 Skill；
- Skill 增删不删除历史回答和已保存成果。

第一版只提供官方内置 Skill：

- 不支持用户创建 Skill；
- 不支持导入第三方 Skill；
- 不提供公开 Skill 市场；
- 原有人物型 Skill 全部保留，并纳入研究目录全部 25 个条目；
- “张雪峰视角”去重后，官方候选规模约 44 个；
- 首页通过问题推荐、分类、搜索和筛选发现 Skill，不平铺全部候选；
- 推荐只提供候选与理由，必须由用户确认后加入。

## 5. 议题与阶段推进

### 5.1 议题

议题是持续容器，承载：

- 背景与约束；
- 对话与协作；
- 已确认资料；
- 阶段节点；
- 判断、分歧和行动；
- 已保存成果。

一个议题只有一条主线，不自动分叉或拆成多个并行议题。需要独立处理时，由用户显式创建或关联新议题。

### 5.2 自由追问

自由追问始终是一级能力，用于补充、质疑、深挖或澄清当前阶段目标。

### 5.3 推进议题

“推进议题”取代旧“下一轮”概念，用于进入新的明确阶段目标：

- 入口始终可用，阶段成熟时增强提示；
- 点击后采用轻量三步流程：选择方向 → 选择措施或填写目标 → 确认目标、Skill、资料与预期成果；
- 只有最终确认后才创建新阶段；
- 默认继承议题背景、已确认资料、已保存成果、当前 Skill 与关键判断；
- 用户可调整目标、Skill、重点资料和成果类型；
- 新阶段仍属于原议题，旧阶段完整保留。

推进方向：

- **拓展新视角**：反方、遗漏视角、关键假设、立场比较、深入问题；
- **形成行动方案**：下一步、执行计划、阻碍、成果交付、检查节点；
- 支持自定义推进目标。

“轮次”只可用于描述模型或成员的一次响应批次，不再作为产品最高层推进对象。

## 6. 圆桌与结果

圆桌是多 Skill 的主要协作形式，不等于整个产品。

- 多 Skill 默认分别独立回应；
- 交叉讨论必须由用户显式触发，并选择参与者和讨论焦点；
- 圆桌不以投票决定真理；
- 收束结果应包含共识、分歧、适用条件、明确建议和下一步；
- 系统可给出推荐及依据，但用户保留最终决定权。

---

## 7. 资料、成果与音频

采用议题内与全局双层结构：

- 议题内管理本议题资料、成果和阶段关系；
- 全局资料库与成果库负责跨议题汇总；
- 每项资料和成果保留来源、所属议题和阶段；
- 音频保留为成果输出形式，并保留与源内容的关系；
- PR08 只定义产品与技术迁移规格，不在本阶段修改音频生产代码。

阶段总结由系统生成草稿，用户编辑确认后才保存为正式成果。默认先生成通用总结，再可转为行动方案、决策记录、知识笔记或交付稿。

## 8. 本地数据与安全

已确认的产品目标：

- V1 本地保存，不做账号和自动云同步；
- 支持手动导入导出；
- 本地库由设备安全密钥保护；
- 应用锁可选，支持生物识别或应用 PIN；
- 导出文件始终加密，使用独立备份密码；
- 非空数据库导入先预览差异，由用户选择合并或替换；
- 第 35～49 题的去重、冲突处理、隔离校验、原子写入、恢复快照、验证、容量提示、回退保护、手动快照和设备绑定规则均已确认。

这些结论冻结用户可见行为和数据安全目标，不提前冻结 Room Schema、具体算法、Kotlin 类型或文件格式。

## 9. 高风险与合规边界

- 医疗、法律、金融等高风险问题采用分级响应，不完全禁止；
- 提供一般信息、分析框架、证据、时效和不确定性说明；
- 不作诊断、法律结论或收益保证；
- 紧急、不可逆或高后果情形应提示并引导寻求现实专业帮助；
- 高风险 Skill 必须披露能力边界、来源、限制和信息时效；
- “Windows 文档生产力助手”只能按 Android 真实可用范围设计，不伪装桌面执行能力；
- 原“规避 AIGC 检测类”转化为“原创表达与写作自然化助手”，禁止绕过检测、隐瞒不允许的 AI 使用、伪造经历或承诺无法被检测。
