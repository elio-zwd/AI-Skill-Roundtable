# PR08-B：信息架构与核心交互

## 元数据

```text
分支：docs/pr-08b-information-architecture
Base：包含 PR #20、#21、#22 的统一 main
独占路径：docs/design/ux/
PR 标题：docs: 设计见域信息架构与核心流程
```

## 信息架构任务

- [ ] 建立问题优先首页；
- [ ] 现实支持、思维拓展可跳过、单选或组合；
- [ ] 系统推荐模式和 Skill 后进入用户确认页；
- [ ] 定义 Skill 推荐、分类、搜索、筛选和详情；
- [ ] 定义议题工作区、阶段时间线、资料和成果位置；
- [ ] 定义全局资料库、成果库和议题来源关系；
- [ ] 评估音频作为成果输出形式的位置；
- [ ] 定义设置、API Key、遥测等系统能力入口。

## 核心流程任务

- [ ] 快速提问并自动建立议题；
- [ ] 显式创建长期议题；
- [ ] 单 Skill 与多 Skill 开始流程；
- [ ] 单 Skill 邀请其他 Skill；
- [ ] 多 Skill 中点名某个 Skill 临时回应；
- [ ] 显式触发交叉讨论并选择参与者和焦点；
- [ ] 自由追问继续当前阶段；
- [ ] “推进议题”始终可用，阶段成熟时增强提示；
- [ ] 三步推进：方向 → 措施/自定义目标 → 确认目标、Skill、资料、成果；
- [ ] 只有最终确认后创建新阶段；
- [ ] 新阶段继承背景、已确认资料、已保存成果、当前 Skill 和关键判断；
- [ ] 旧阶段完整保留；
- [ ] 归档、关联新议题、继续归档议题；
- [ ] 删除、彻底清除、停止、恢复、重试和进程重建。

## 推进措施

### 拓展新视角

- [ ] 反方；
- [ ] 遗漏视角；
- [ ] 关键假设；
- [ ] 立场比较；
- [ ] 深入问题。

### 形成行动方案

- [ ] 下一步；
- [ ] 执行计划；
- [ ] 阻碍；
- [ ] 成果交付；
- [ ] 检查节点。

- [ ] 支持自定义推进目标。

## 状态矩阵

至少覆盖：

- [ ] 空状态；
- [ ] 有历史议题；
- [ ] 加载、思考、搜索和流式输出；
- [ ] 部分成功与全部失败；
- [ ] 用户停止；
- [ ] 无 API Key、无网络、材料失败；
- [ ] 推荐取消或修改；
- [ ] 推进中取消、误触和恢复；
- [ ] 窄屏、明暗主题和无障碍。

## 完成判定

- [ ] 自由追问与推进议题都是一级能力；
- [ ] 一个议题保持单一主线，不自动分叉；
- [ ] 所有关键动作有进入、确认、取消、失败和恢复条件；
- [ ] 不强制用户先选模式或 Skill。
