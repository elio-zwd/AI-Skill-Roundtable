## 2. 第 7 章验收标准的适用阶段

规格审阅稿第 7 章标题为“可验证验收标准”。其正确含义是：

> **第 7 章是规格冻结、PR08-F 最终整合以及后续 PR09 实现时需要逐步满足的目标验收标准，不代表 PR #22 当前已经满足全部条目。**

具体分层如下：

| 验收层级 | 当前 PR #22 是否必须满足 | 说明 |
|---|---:|---|
| 文档状态、题号映射、术语一致性 | 是 | 当前文档 PR 的直接门禁 |
| README、AGENTS 与 PR08 阶段边界一致 | 是 | 当前 PR 已纳入处理 |
| 首页、Skill、议题、圆桌等产品行为 | 否 | PR08-B/C/D 输出规格，PR09 才实施 |
| 本地加密、导入、清除、恢复快照 | 否 | 先通过规格审核，再进入技术评估和实现 |
| Android UI、Room、导航、资源迁移 | 否 | PR09 生产实现范围 |

因此，第 7 章中未勾选的条目不是“当前 PR 已失败”的声明，也不能在 PR #22 中被标记为已经实现。
