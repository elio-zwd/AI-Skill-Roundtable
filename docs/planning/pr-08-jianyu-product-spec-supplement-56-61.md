## 2. 第 56 题：推进议题

### 2.1 第 56.1 题：入口时机

采用 A：

- 正式入口名称为 **推进议题**；
- 入口始终可用；
- 阶段成熟时可以增强提示并解释理由；
- 用户不需要等待系统许可；
- 不强制用户推进或结束当前阶段；
- 用户可以继续自由追问、保存成果、调整 Skill 或暂不推进。

“推进议题”不是暂定名称，后续视觉设计可以调整承载方式、图标和辅助说明，但不得更改正式名称和产品语义。

### 2.2 第 56.2 题：三步确认

采用 A：

1. 选择推进方向；
2. 选择具体措施或自定义目标；
3. 确认下一阶段摘要。

只有第三步最终确认后才创建新阶段。返回、取消或关闭流程时，原阶段保持不变，不创建空阶段或重复历史副本。

### 2.3 第 56.3 题：默认继承和调整

默认继承：

- 议题背景；
- 已确认资料；
- 已保存成果；
- 当前 Skill 阵容；
- 已形成判断；
- 主要分歧；
- 当前行动项。

用户可调整：

- 下一阶段目标；
- Skill；
- 资料；
- 输出形式。

默认继承不等于把全部历史原文重新复制或发送给模型；具体上下文压缩和隐私实现由 PR08-E 评估。

### 2.4 第 56.4 题：阶段关系

采用 A：

- 新阶段仍属于原议题；
- 旧阶段完整保存；
- 新阶段不覆盖旧阶段；
- 一个议题保持单一主线；
- 不自动创建分支议题；
- 不自动复制互相冲突的历史副本；
- 需要独立主线时由用户显式创建或关联新议题。

### 2.5 与自由追问的关系

- 自由追问继续当前阶段；
- 推进议题建立新的明确阶段目标；
- 两者都是一级能力；
- 普通自然语言输入不得被系统擅自解释为阶段推进；
- 推进议题不要求全部 Skill 重新回答；
- “下一轮”只作为历史术语。

## 3. 第 57 题：正式方向与措施

选择 A。第一步正式方向为：

### 3.1 思维拓展

- 引入反方意见；
- 查找遗漏视角；
- 检查关键假设；
- 比较不同立场；
- 深入某个问题；
- 自定义目标。

### 3.2 现实支持

- 明确下一步；
- 形成执行计划；
- 分析执行阻碍；
- 生成成果交付；
- 设置检查节点；
- 自定义目标。

预设措施用于帮助表达目标，不限制用户自定义目标。不得以“拓展新视角／形成行动方案”替换正式方向名称；这些词只能作为解释性文案。

## 4. 第 58 题：两类核心价值名称

选择 A。正式名称继续使用：

- **现实支持**
- **思维拓展**

界面可以附加通俗说明，但不得替换正式名称。

规则：

- 可以跳过、单选或组合；
- 同一议题可以反复切换；
- 不是永久标签；
- 不自动拆成两条议题线；
- 首页不得强迫用户先选方向；
- “生活与工作”“思维与视角”“现实行动”不是正式分类名。

## 5. 第 59 题：官方 Skill 候选范围

### 5.1 范围

- 原有人物型 Skill 全部保留；
- 纳入研究目录全部 25 个条目；
- “张雪峰视角”与现有资产去重；
- 去重后官方候选约 44 个；
- 最终数量以 PR08-C 的逐项核验为准；
- V1 不支持用户创建、第三方导入或公开市场。

### 5.2 类型

官方 Skill 至少覆盖：

1. 人物视角；
2. 专业顾问；
3. 任务助手；
4. 工作流能力。

Skill 可以拥有多个标签。首页不平铺全部候选，应通过问题推荐、分类、搜索和筛选发现。系统推荐必须说明理由并由用户确认。

### 5.3 Windows 文档生产力助手

- 可进入官方候选池；
- Android 无法直接执行的桌面自动化不得伪装为可执行功能；
- 可保留为内容组织、工作流规划、检查清单或成果生成能力；
- PR08-E 评估移动端文件处理、依赖、许可证和隐私风险。

### 5.4 原创表达与写作自然化助手

原“规避 AIGC 检测类”改为 **原创表达与写作自然化助手**。

允许：

- 改善机械、重复和不自然表达；
- 帮助用户澄清真实观点、经历和证据；
- 调整结构、语气和可读性；
- 检查事实、引用和原创性声明；
- 提醒遵守学校、单位、平台和出版要求。

禁止：

- 绕过 AIGC、抄袭、学术或招聘检测；
- 隐瞒不允许的 AI 使用；
- 伪造经历、数据、引用、作者身份或原创过程；
- 承诺无法被检测；
- 提供对抗检测系统的技巧。

## 7. 第 61 题：高风险问题

选择 A，采用分级响应，不完全禁止。

### 一般风险

可以正常提供分析、建议和行动方案，同时说明关键假设和适用条件。

### 较高风险

医疗、法律、金融等领域：

- 只提供一般信息、分析框架和可核查依据；
- 说明不确定性、适用条件和信息时效；
- 重要决定前提示具备资质的专业人员复核；
- 不把 AI 输出描述为正式诊断、法律意见、投资保证或专业执照意见。

### 紧急或重大不可逆风险

- 优先提示风险和现实帮助；
- 不自动执行决定；
- 不提供绕过安全、法律或专业审查的操作方案；
- 根据场景提供适当人工帮助入口。

高风险 Skill 必须披露能力边界、来源、限制和时效。
