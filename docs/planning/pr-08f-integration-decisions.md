## 2. 已确认且必须吸收的补充默认行为

以下内容不再作为待决定项：

1. 用户可以不生成正式成果，直接推进议题；只有经用户确认保存的阶段总结才成为正式成果。
2. 归档议题可以恢复继续；恢复时保留原阶段、消息、资料和成果，同时保留“基于此议题创建关联新议题”的独立入口。
3. 长期个人背景按议题显式带入；背景可保存到个人背景库，但新议题必须由用户明确选择是否使用，并展示本次实际使用的背景。
4. 显式交叉讨论默认仅对当前指令生效；完成后恢复各 Skill 默认独立回应。
5. V1 可以保存官方内置 Skill 的组合与顺序，但不开放用户自定义 Skill。

## 3. 本轮用户确认的产品行为

### D-01 首页支持“仅保存议题”

**决定：纳入 V1。**

- 首页提供“保存议题”次级操作；
- 该操作只创建议题草稿，不推荐 Skill、不调用模型、不创建执行运行；
- 用户之后可从议题列表继续完善、选择资料与个人背景、确认 Skill 并开始运行；
- “保存议题”不得被表现为已经生成内容或已经开始圆桌。

### D-02 未运行新阶段允许撤销

**决定：允许撤销，不使用倒计时。**

- 新阶段完成最终确认并创建后，在首次模型调用或其他执行运行开始前，可以撤销；
- 撤销后回到上一阶段，并删除该空阶段及其尚未提交的运行设置；
- 一旦新阶段已经开始执行，不再提供“撤销阶段”，改用停止、归档或后续推进能力；
- 撤销不得删除上一阶段的消息、资料、成果或历史快照。

### D-03 阶段总结草稿持久保存

**决定：跨 Activity 与进程重建持久保存，不自动过期。**

草稿保留到以下任一条件发生：

- 用户确认保存为正式成果；
- 用户主动放弃草稿；
- 所属议题被彻底清除。

普通退出、Activity 重建、进程被系统回收和应用重新打开不得静默丢失草稿。

### D-04 普通删除进入无自动过期回收站

**决定：普通删除与彻底清除分离。**

- 普通删除进入回收站；
- 回收站内容不设置自动过期时间；
- 用户可以恢复或主动执行“彻底清除”；
- 容量不足时只提醒，不静默删除回收站内容；
- 彻底清除前必须明确说明不可恢复范围。

### D-05 运行中归档需要显式选择

**决定：运行期间不直接静默归档。**

用户触发归档时，提供两个明确选择：

1. 继续等待当前生成完成，完成后再归档；
2. 停止当前生成并归档。

不得默认静默停止，也不得在仍运行时仅改变界面状态造成“已经归档”的误解。

### D-06 特殊 Skill 用户侧名称

**决定：`original-expression-naturalizer` 的用户侧中文名称为“去AI化助手”。**

该名称必须与以下能力边界同时出现，不得脱离边界单独宣传：

- 只根据用户提供的真实事实、关系背景和行动目标，生成或优化可直接发送、提交或使用的现实沟通文本；
- 目标是减少生硬、模板化和机械表达，让文字更符合用户本人的语气与场景；
- 不以绕过 AI 检测、学术诚信检查、平台审核或组织规则为目标；
- 不承诺“不可检测”“检测通过”或任何检测结果；
- 不伪造经历、数据、引用、身份或他人观点；
- 不删除必须保留的 AI 使用声明、来源说明或诚信披露；
- 不负责整理多个 Skill 的意见、统一圆桌观点或掩盖分歧。

为降低名称歧义，Skill 详情页必须显示一句固定边界说明：

> 让真实内容更像你本人表达，不用于规避检测或伪造事实。

### D-07 最终视觉采用统一比较板决策

**决定：当前不锁定候选 A。**

PR08-F 必须在相同文案、信息架构和页面状态下比较：

- 候选 0：原有已完成视觉版本；
- 候选 A：开域窗；
- 候选 B：域界折页；
- 候选 C：多视线汇聚。

至少比较：App Icon、首页、推荐确认、单／多 Skill 议题工作区、推进议题三步面板、阶段时间线、明暗主题和窄屏状态。

允许形成混合方案。用户看到可比较预览并明确确认前：

- 不锁定最终 Logo；
- 不锁定最终 App Icon；
- 不宣称主视觉方向已最终批准；
- 候选 A 仅保留为当前推荐深化方向。

## 4. PR08-F 直接统一、不再提交用户选择的事项

### 4.1 推进方向组合控件

“现实支持”和“思维拓展”使用两个可独立选择的方向卡片：

- 可跳过；
- 可单选；
- 可同时选择；
- 同时选择不创建两条议题主线；
- 精确间距、断点和动效由最终视觉规格决定。

### 4.2 资料与成果导航

采用一个产品级入口“资料与成果”，页面内使用“资料 / 成果”两个 Tab：

- 避免底栏一级入口过多；
- 资料与成果仍是两个不同产品对象；
- 支持按议题、阶段、Skill、来源和时间筛选；
- 深链可以直接打开指定 Tab 和指定对象。

### 4.3 44 项 Skill 分批原则

- 44 项全部属于 V1 阶段目标；
- 允许按 V1.0、V1.1 等批次交付；
- 不按人物视角、专业顾问、任务助手、工作流能力四类机械切批；
- 按许可清晰度、移动端可行性、安全与来源治理、内容质量、实现完成度和测试证据划分；
- 未通过门禁的候选不得展示为已可用；
- 人物争议或风险标签不得作为降低自动推荐排名的依据。

### 4.4 `testTag` 迁移原则

- 新标签采用“页面域 + 对象／语义动作 + 状态”的稳定命名；
- 禁止把显示文案直接作为长期测试标识；
- 旧标签保留到对应新页面测试完成迁移，并经过至少一个完整稳定验收周期；
- 兼容期结束前，测试和文档必须维护新旧映射表；
- 精确标签字符串由 PR09 对照现有测试后确定。
