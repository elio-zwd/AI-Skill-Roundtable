# AI 智囊圆桌 · 独立 Skills 研究区

此目录与主项目工作树完全分离，用于收集、筛选和改写适合「AI 智囊圆桌」的 Skill 候选项。不会自动写入 `AI-Skill-Roundtable/app`，也不会下载或执行任何第三方仓库脚本。

## 产物

- `catalog/skills-catalog.json`：可追溯的候选清单；一项 Skill 可拥有多个分类标签。
- `catalog/taxonomy.yaml`：面向 App 的分类树与安全边界。
- `app-ready-skills/`：原创、App 兼容的 `SKILL.md` 草案，供人工审查后再选择性接入。
- `sources/`：检索批次和来源记录。

## 适配原则

1. 每个草案都使用 App 现有的入口格式：目录下的 `SKILL.md`，包含 YAML frontmatter，正文可直接作为系统提示词加载。
2. 草案只借鉴公开项目的**能力方向和工作流**；不复制第三方 `SKILL.md` 正文、脚本、角色语料、肖像或私有数据。
3. 所有项目都必须在接入主项目之前重新核验许可证、上游版本、内容安全和隐私风险。
4. 涉及法律、医疗、金融、命理、求职与人际关系的 Skill 只能提供教育、整理和沟通辅助，不能替代专业意见或做确定性承诺。

## 与当前 App 的差异

当前 App 的 `skills_config.json` 还没有多分类字段；本研究区将分类放在独立清单的 `tags` 中。后续若接入，需要新增或映射 UI 分类方案，但本阶段不改主项目。
