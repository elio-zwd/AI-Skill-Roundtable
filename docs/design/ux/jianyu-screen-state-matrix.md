# 见域页面状态矩阵

> 文档状态：PR08-B 页面状态规格草案  
> 适用范围：目标产品“见域”  
> 启动基线：`main@d6db5e1b825bab60852b6365eef0ef6deb5bb970`  
> 关联文档：[见域信息架构](./jianyu-information-architecture.md)；[见域核心交互流程](./jianyu-core-flows.md)  
> 重要说明：本文定义页面必须表达的状态、动作、优先级和恢复边界，不代表当前 Android App 已经实现，也不冻结 Compose 组件、颜色、图标、动画、Route、UiState 类型或持久化方案。

## 1. 结论

见域页面状态必须同时表达六个维度：

```text
内容状态：空 / 加载 / 有内容 / 无结果 / 失效
运行状态：准备 / 搜索 / 思考 / 流式 / 成功 / 部分成功 / 全部失败 / 已停止
环境状态：在线 / 离线 / 无 Key / 限流 / 服务不可用
资料状态：待确认 / 处理中 / 可用 / 部分失败 / 全部失败 / 时效未核验
决策状态：未开始 / 待确认 / 已确认 / 已取消 / 需修正
恢复状态：可恢复 / 已恢复 / 无法恢复 / 需要用户决定
```

状态设计遵守：

1. 不用颜色作为唯一信号；
2. 状态必须给出下一步，而不是只显示错误；
3. 用户输入、已完成内容和已确认选择优先保留；
4. 部分成功不能退化为全部失败；
5. 无 Key、离线、资料失败和 Skill 不可执行必须区分；
6. 用户停止与系统失败必须区分；
7. 误触、取消和进程重建不能越过确认门禁；
8. 阶段总结草稿不能显示为正式成果；
9. 响应批次和 `roundIndex` 不能显示为阶段；
10. “推进议题”始终可用，运行中可暂时禁用提交但不能从信息架构中消失；
11. 所有页面在窄屏、明暗主题和辅助技术下保持等价行为。

## 2. 状态优先级

同一页面可能同时存在多个状态。显示优先级如下：

```text
紧急现实安全
> 数据损坏或不可逆风险
> 需要用户确认的高风险动作
> 当前运行失败 / 停止 / 恢复
> 无 Key / 离线 / 服务不可用
> 资料失败或时效未核验
> 页面加载 / 空 / 无结果
> 普通内容
```

规则：

- 高优先级状态不得被低优先级 Toast 覆盖；
- 页面级错误与单项错误分开；
- 单项失败不替换整个页面；
- 高风险确认不与普通推荐确认合并；
- 多个可恢复动作只能有一个主要继续入口；
- Snackbar 只承担短期反馈，不承担不可逆影响说明；
- 进程重建后的恢复卡片优先于普通“继续最近议题”。

## 3. 全局状态组件职责

| 状态组件 | 适用 | 必须包含 | 不适用 |
|---|---|---|---|
| 页面空状态 | 当前集合确实为空 | 原因、主要入口、可选帮助 | 加载尚未完成 |
| 页面加载状态 | 首次读取或全页刷新 | 正在做什么、可取消性 | 无限无说明转圈 |
| 行内状态 | 单个 Skill、资料、成果或消息 | 对象名称、状态、动作 | 替代页面级错误 |
| 运行状态卡 | 模型调用、交叉讨论、成果生成 | 阶段、参与者、进度、停止 | 仅视觉动画 |
| 阻断页 | 无 Key、必须联网、数据不可用 | 原因、修复、返回 | 可降级的小问题 |
| 恢复卡 | 未完成动作或进程重建 | 发生了什么、已保留什么、下一步 | 自动重复调用 |
| 确认面板 | 用户决策门禁 | 影响、选择、确认、取消 | 默认勾选高风险项 |
| 结果反馈 | 保存、归档、删除、导出 | 成功或失败、影响、后续入口 | 模糊“操作完成” |

## 4. 首页状态矩阵

| 状态 | 触发 | 页面表现 | 主要动作 | 次要动作 | 禁止 |
|---|---|---|---|---|---|
| 首次空状态 | 无历史议题 | 问题输入优先，价值选择可跳过 | 输入问题 | 查看示例、浏览 Skill | 强迫先选模式 |
| 有历史议题 | 存在活跃或归档议题 | 问题输入 + 最近议题摘要 | 提新问题 | 继续议题 | 用历史遮挡输入 |
| 输入中 | 用户正在编辑 | 保留文本、资料和价值选择 | 提交 | 清空、保存临时输入 | 自动提交 |
| 推荐准备中 | 已提交问题 | 说明正在分析目标、风险和 Skill | 取消 | 查看输入摘要 | 显示无解释名单 |
| 推荐失败 | 无法生成建议 | 保留问题，显示可读原因 | 重试 | 浏览 Skill、修改问题 | 清空输入 |
| 无合适 Skill | 能力缺口 | 解释缺口和限制 | 修改问题 | 浏览目录 | 强行推荐人物 |
| 无可执行 Skill | 候选均未过门禁 | 显示开发或门禁状态 | 修改问题 | 查看候选详情 | 伪装可开始 |
| 无 Key | 开始前检查失败 | 阻断调用，保留输入 | 配置 Key | 返回编辑 | 丢失问题 |
| 离线可降级 | 当前任务联网可选 | 标记未核验 | 继续离线 | 等待网络 | 显示为最新 |
| 离线阻断 | 当前任务必须联网 | 说明原因 | 等待网络 | 提供资料、取消 | 自动重复请求 |
| 恢复未完成输入 | 进程重建 | 显示恢复来源和时间 | 继续编辑 | 放弃 | 自动提交 |
| 恢复待确认推荐 | 进程重建 | 显示推荐仍未确认 | 继续确认 | 返回编辑、放弃 | 自动创建议题 |

### 4.1 首页窄屏

- 问题输入始终在首屏主要位置；
- 现实支持、思维拓展采用可换行或纵向选择；
- 最近议题放在输入之后；
- 恢复卡不与问题输入争夺唯一主按钮；
- 键盘打开时仍可看到提交或取消状态。

## 5. 推荐确认状态矩阵

| 状态 | 条件 | 必须展示 | 主要动作 | 恢复规则 |
|---|---|---|---|---|
| 加载 | 生成推荐中 | 问题摘要、当前分析步骤 | 取消 | 返回首页保留输入 |
| 待确认 | 推荐完成 | 模式理由、Skill 理由、风险、资料、输出 | 确认开始 | 本地临时保留选择 |
| 用户修改 | 增删 Skill 或改模式 | 差异、重复、职责变化 | 重新确认 | 不自动开始 |
| Skill 详情展开 | 查看候选 | 能力、边界、来源、时效 | 返回确认 | 保留滚动与选择 |
| 重复冲突 | 能力重叠 | 重叠原因和三种处理 | 选择处理 | 未处理时阻止最终确认或明确提醒 |
| 高风险缺口 | 缺少核查或专业边界 | 条件、不确定性、现实复核建议 | 调整阵容 | 不把人物当裁决者 |
| 资料不足 | 缺少必要输入 | 缺失项、可降级后果 | 添加资料 | 允许取消或降级 |
| 资料处理中 | 读取或解析 | 每项进度 | 等待或取消 | 已成功项保留 |
| 资料部分失败 | 部分可用 | 成功与失败清单 | 仅用成功项继续 | 允许重试失败项 |
| 资料全部失败 | 无可用资料 | 原因和影响 | 替换或重试 | 不开始依赖资料的运行 |
| 无 Key | 最终确认前检查 | Key 缺失 | 配置 Key | 返回原确认页 |
| 候选状态变化 | Skill 执行资格改变 | 变化原因 | 替换或重新确认 | 原确认失效但选择保留 |
| 确认提交中 | 用户已确认 | 正在创建议题和阶段 | 等待 | 防重复提交 |
| 创建失败 | 原子提交失败 | 未创建或回滚状态 | 重试 | 保留全部选择 |
| 取消 | 用户退出 | 确认是否保留输入 | 返回首页 | 不创建对象 |
| 进程重建 | 页面恢复 | 标记仍为待确认 | 继续确认 | 不越过门禁 |

禁止：

- 预选高风险个人背景；
- 推荐理由为空仍允许直接开始；
- Skill 详情关闭时丢失选择；
- 提交按钮连续点击创建重复议题；
- 只显示“多 Skill 更好”而无具体职责；
- 将“收藏”视为“加入”。

## 6. Skill 发现与详情状态矩阵

### 6.1 Skill 发现

| 状态 | 页面表现 | 动作 |
|---|---|---|
| 首次加载 | 分类骨架或明确加载说明 | 取消刷新 |
| 有内容 | 四类主类型、搜索、筛选、状态标签 | 进入详情 |
| 空查询 | 最近使用、收藏、分类入口 | 输入搜索 |
| 搜索中 | 保留查询与已应用筛选 | 取消搜索 |
| 有结果 | 显示匹配原因 | 详情、收藏、用于问题 |
| 无结果 | 显示查询与筛选冲突 | 改词、清除筛选 |
| 搜索失败 | 保留查询 | 重试 |
| 离线 | 显示本地目录与时效状态 | 继续浏览 |
| 目录加载失败 | 页面级错误 | 重试、返回首页 |
| 部分条目失败 | 失败条目占位 | 单项重试 |
| 门禁待完成 | 卡片显示不可执行原因 | 查看详情 |
| 无障碍筛选 | 筛选数量和选中状态可读 | 清除、应用 |

### 6.2 Skill 详情

| 状态 | 必须表达 | 可用动作 | 禁止 |
|---|---|---|---|
| 加载 | Skill 标识和加载状态 | 返回 | 空白页 |
| 可执行 | 能力、边界、输入输出、风险、来源 | 用于新问题、加入当前议题 | 未确认直接调用 |
| 开发中 | 当前不可执行原因 | 收藏、查看状态 | 显示“开始” |
| 来源待核验 | 来源和许可状态 | 查看说明 | 暗示已发布 |
| 人物模拟 | 非本人声明、时效、适用边界 | 作为补充视角 | 冒充本人 |
| 高风险 | 专业边界和现实复核 | 加入确认 | 保证结论 |
| 详情失败 | 卡片摘要和错误 | 重试 | 丢失来源页 |
| 加入确认 | 当前议题、职责和影响 | 确认加入 | 自动带入全部聊天 |
| 替换确认 | 替换前后职责 | 确认替换 | 删除历史回答 |

## 7. 议题列表状态矩阵

| 状态 | 表现 | 主要动作 | 次要动作 |
|---|---|---|---|
| 首次空状态 | 解释议题是持续容器 | 提出问题 | 新建议题 |
| 有活跃议题 | 当前阶段、更新时间、阵容、运行状态 | 继续 | 搜索、筛选 |
| 仅有归档议题 | 归档说明 | 查看归档 | 提出新问题 |
| 加载 | 列表加载说明 | 等待 | 返回首页 |
| 刷新失败 | 保留旧列表，标记刷新失败 | 重试 | 继续旧内容 |
| 搜索中 | 查询和范围 | 取消 | — |
| 无结果 | 显示筛选条件 | 清除筛选 | 提出新问题 |
| 有未完成运行 | 议题卡显示恢复状态 | 恢复 | 放弃运行 |
| 有部分失败 | 显示失败成员数 | 打开议题 | — |
| 归档中 | 单项进度 | 等待 | 取消（若尚未提交） |
| 归档失败 | 原状态保持 | 重试 | 查看原因 |
| 删除中 | 防重复操作 | 等待 | — |
| 进程重建 | 恢复列表位置和筛选 | 继续 | 重置筛选 |

议题卡不得把响应批次数量显示成阶段数量。

## 8. 议题工作区状态矩阵

### 8.1 内容状态

| 状态 | 阶段内容 | 输入区 | 推进议题 | 其他动作 |
|---|---|---|---|---|
| 新阶段空内容 | 显示阶段目标和继承摘要 | 可输入 | 可用 | 邀请 Skill、资料 |
| 有历史消息 | 消息与来源关系 | 可输入 | 可用 | 时间线、成果 |
| 查看旧阶段 | 只读旧阶段标识 | 默认禁用发送 | 可从当前阶段使用 | 返回当前阶段 |
| 归档只读 | 归档标识 | 不直接发送 | 不直接创建 | 继续或关联新议题 |
| 阶段总结草稿 | 草稿标识 | 可继续追问 | 可用 | 编辑、确认、放弃 |
| 正式成果已保存 | 成果入口和来源 | 可继续追问 | 可用 | 查看成果 |

### 8.2 运行状态

| 状态 | 消息区 | 阵容区 | 输入与动作 | 完成后 |
|---|---|---|---|---|
| 准备 | 显示即将参与的 Skill | 固定本次参与者 | 可取消 | 开始搜索或思考 |
| 排队 | 显示等待原因 | 标记等待 | 可停止 | 进入运行 |
| 搜索中 | 显示正在核验的主题，不泄露敏感查询 | 标记核查者 | 可停止 | 进入思考 |
| 思考中 | 每个参与者状态可见 | 等待 / 处理中 | 停止可用 | 进入流式 |
| 流式输出 | 已接收正文持续更新 | 当前参与者高亮但不只靠颜色 | 停止可用 | 成功或失败 |
| 单 Skill 成功 | 完整回复 | 完成 | 自由追问、成果 | 保留当前阶段 |
| 多 Skill 全部成功 | 各回复与职责 | 全部完成 | 交叉讨论、整合、推进 | 保留响应批次 |
| 部分成功 | 成功内容 + 失败成员 | 成功/失败分开 | 重试失败、忽略 | 不删成功内容 |
| 全部失败 | 用户输入 + 失败摘要 | 全部失败 | 修正、重试、取消 | 不生成伪结果 |
| 用户停止中 | 正在停止 | 逐项停止 | 防重复点击 | 已停止 |
| 已停止 | 保留已完成内容 | 标记停止 | 继续、重试 | 不显示完成 |
| 重试中 | 仅失败目标重新运行 | 固定失败子集 | 停止 | 合并到原请求 |
| 整合失败 | 原回复保留 | 参与者完成 | 重试整合 | 不重跑全部 |
| 运行恢复 | 显示重建前状态 | 参与者快照 | 继续、重试、放弃 | 不重复已完成调用 |
| 无法恢复 | 显示已保留内容和原因 | 未知项明确 | 新建重试 | 不猜测原状态 |

### 8.3 环境和资料状态

| 状态 | 页面级还是单项 | 用户动作 |
|---|---|---|
| 无 Key | 页面阻断当前调用 | 配置 Key，返回恢复 |
| Key 全部受限 | 页面阻断当前调用 | 查看状态、稍后重试 |
| 离线可降级 | 运行卡提示 | 继续离线 |
| 离线阻断 | 当前运行阻断 | 等待、提供资料、取消 |
| 搜索服务失败 | 当前步骤失败 | 重试搜索或不用搜索继续 |
| 单项资料失败 | 单项 | 重试、替换、移除 |
| 多项资料部分失败 | 运行卡 | 仅用成功项继续 |
| 资料全部失败 | 阻断依赖资料的请求 | 替换或取消 |
| 资料时效未核验 | 单项提示 | 联网核验或接受限制 |
| 敏感资料限制 | 页面确认 | 不联网、移除或取消 |

### 8.4 误触与取消

| 行为 | 防护 |
|---|---|
| 误触停止 | 状态立即可见；若调用尚未开始可取消停止 |
| 误触点名 | 发送前显示本次回答者 |
| 误触移除 Skill | 影响确认，不删除历史 |
| 误触推进议题 | 打开面板不创建阶段 |
| 误触归档 | 归档确认 |
| 误触删除 | 删除确认 |
| 连续点击发送 | 幂等或按钮状态防重复 |
| 系统返回 | 不丢失未发送输入 |

## 9. 单 Skill、多 Skill、点名与交叉讨论状态

| 模式 / 状态 | 阵容表现 | 输入默认 | 关键动作 | 不改变 |
|---|---|---|---|---|
| 单 Skill | 一个主要 Skill | 该 Skill | 邀请其他 Skill | 议题与阶段 |
| 邀请待确认 | 候选和职责 | 不发送 | 确认 / 取消 | 原阵容 |
| 多 Skill | 多个 Skill 与职责 | 系统建议参与者或用户选择 | 点名、交叉讨论 | 不要求全员发言 |
| 临时点名 | 本次目标突出 | 仅该 Skill | 发送 / 取消点名 | 多 Skill 模式 |
| 长期切换单 Skill待确认 | 展示移除默认参与影响 | 不发送 | 确认 / 取消 | 历史回答 |
| 交叉讨论配置 | 至少两个参与者和焦点 | 不适用 | 确认 / 取消 | 当前阶段 |
| 交叉讨论运行 | 参与者逐项状态 | 禁止重复发起同一运行 | 停止 | 不自动新阶段 |
| 交叉讨论部分成功 | 成功与失败分开 | — | 重试失败 / 整合 | 成功内容 |
| 交叉讨论整合 | 共识、分歧、条件、建议、下一步 | — | 重试整合 | 原始回应 |

表达类 Skill 不得因加入阵容自动取得其他 Skill 全部输出；用户确认的现实沟通文案任务例外地只接收用户选定的真实事实和行动内容。

## 10. 推进议题三步状态矩阵

### 10.1 总状态

| 状态 | 是否已有新阶段 | 可用动作 |
|---|---:|---|
| 未打开 | 否 | 打开 |
| 第一步待选择 | 否 | 选择方向、取消 |
| 第二步待选择 | 否 | 选择措施、填写目标、返回、取消 |
| 第三步待确认 | 否 | 调整、返回、最终确认、取消 |
| 正在创建 | 尚未对用户确认成功 | 等待，防重复提交 |
| 创建成功 | 是，且仅一个 | 进入新阶段 |
| 创建失败 | 否或已回滚 | 重试、返回原阶段 |
| 恢复待确认 | 否 | 继续或放弃 |
| 恢复已确认创建 | 是 | 打开已创建阶段 |
| 无法确定 | 不得猜测 | 回到原阶段并说明 |

### 10.2 第一步：方向

- 可选思维拓展；
- 可选现实支持；
- 正式支持两类组合；使用两个可独立选择的方向卡，同时选择仍只创建一个新阶段；
- 不默认永久记住；
- 取消回到原阶段；
- 不创建时间线节点。

### 10.3 第二步：措施或自定义目标

| 状态 | 表现 | 校验 |
|---|---|---|
| 未选择 | 两类措施列表 | 不能进入第三步，除非填写自定义目标 |
| 已选择预设 | 显示可编辑目标 | 目标需可理解 |
| 自定义输入中 | 保留文本 | 非空且明确 |
| 建议生成中 | 显示来源为系统建议 | 可取消 |
| 建议失败 | 保留用户输入 | 可手动填写 |
| 返回第一步 | 保留合理临时内容 | 方向改变时提示不兼容措施 |

### 10.4 第三步：确认摘要

必须可检查：

- 下一阶段目标；
- 方向与措施；
- 默认继承；
- Skill 阵容；
- 重点资料；
- 预期输出；
- 风险与时效；
- 原议题和当前阶段来源。

状态：

| 状态 | 主要动作 | 禁止 |
|---|---|---|
| 摘要完整 | 最终确认 | 自动倒计时确认 |
| 缺少必要 Skill | 调整 Skill | 伪装可开始 |
| 资料失败 | 替换、移除、降级 | 静默忽略 |
| 高风险缺口 | 增加核查或接受边界 | 隐藏风险 |
| Skill 状态变化 | 替换或重新确认 | 沿用失效确认 |
| 用户取消 | 返回原阶段 | 创建空阶段 |
| 误触确认未写入 | 取消 | 强制创建 |
| 创建中进程重建 | 恢复事务结果 | 重复创建 |

### 10.5 阶段成熟提示

| 状态 | 行为 |
|---|---|
| 未成熟 | 入口仍可用，普通强调 |
| 较成熟 | 增强提示并说明理由 |
| 用户忽略 | 提示降回普通，不反复打断 |
| 用户继续追问 | 保持当前阶段 |
| 用户打开 | 进入第一步 |
| 提示计算失败 | 不影响入口 |

## 17. 状态组合规则

### 17.1 页面加载与离线

- 有缓存内容时保留内容并显示离线；
- 无缓存且必须联网时使用阻断状态；
- 不把离线误报为“无结果”。

### 17.2 流式输出与资料失败

- 已开始生成后某项资料失败，标记该资料未使用或部分使用；
- 不静默把失败资料当成成功来源；
- 允许停止或继续基于已成功资料。

### 17.3 部分成功与阶段成熟

- 部分成功可以提供推进提示，但必须说明缺失观点；
- 不把不完整结果包装为完整共识；
- 用户仍可推进，但第三步需显示风险。

### 17.4 归档与运行中

- 运行中不能直接归档；
- 用户选择等待或停止；
- 归档成功后不自动继续运行。

### 17.5 无 Key 与待确认

- 无 Key 不应清除推荐确认；
- 配置完成后返回待确认；
- 用户再次确认是否开始。

### 17.6 旧阶段查看与新输入

- 查看旧阶段时默认不允许直接发送到旧阶段；
- 提供回到当前阶段；
- 独立主线使用关联新议题；
- 不在旧阶段自动创建分支。

## 20. 无障碍状态要求

### 20.1 屏幕阅读器

- 页面标题和当前议题、阶段先被读出；
- Skill 卡读出名称、类型、职责、风险和选择状态；
- 运行状态按重要变化播报，不逐字符播报；
- 部分成功读出成功与失败数量；
- 推进议题读出当前步骤和总步骤；
- 草稿和正式成果状态明确；
- 危险确认读出不可恢复影响；
- 搜索结果更新使用适度实时区域。

### 20.2 焦点

- 打开面板后焦点进入标题；
- 关闭后回到触发按钮；
- 错误出现时焦点可到达错误摘要，但不强制打断输入；
- 提交失败后回到首个需修正字段；
- 进程重建后焦点进入恢复说明；
- 长列表返回后恢复原项目位置；
- 系统返回与顶部返回保持一致。

### 20.3 动效与时间

- 支持减少动效；
- 不以动画完成作为状态完成依据；
- 限时提示可暂停或有替代；
- 流式输出和进度动画不造成高频闪烁；
- 用户有足够时间阅读高风险确认。

### 20.4 操作

- 触控目标满足平台最低尺寸；
- 长按、滑动和手势都有可见替代；
- 拖动排序有按钮替代；
- 彻底清除不能依赖手势确认；
- 键盘和辅助开关可以完成所有关键流程。

## 24. PR08-F 协调结果

1. 首页正式支持仅保存议题且不开始运行；
2. 推进议题第一步支持两个方向卡单选或组合；
3. 已创建但尚未运行的新阶段允许无倒计时撤销；
4. 阶段总结草稿跨 Activity 和进程重建保留，不自动过期；
5. 普通删除进入无自动过期回收站；
6. 运行中归档不设默认选项，由用户选择等待完成或停止生成；
7. 全局使用一个“资料与成果”入口和两个页内 Tab；
8. 音频作为可关联成果资产，支持筛选并保留派生关系；
9. 新 `testTag` 使用稳定语义命名，旧标签保留一个完整稳定验收周期；
10. 逻辑状态与持久化模型的精确映射留给 PR09 工程设计，不改变以上产品行为。
