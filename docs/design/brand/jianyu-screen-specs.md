# 见域页面视觉规格

> 状态：PR08-D 页面视觉承载草案
> 基线：`main@d6db5e1b825bab60852b6365eef0ef6deb5bb970`
> 本文严格继承 PR08-B 的信息架构、确认、取消、失败和恢复规则，只定义视觉层级、组件组合、响应式与无障碍承载，不冻结 Android Route、Room、UiState、推荐算法或 Compose 实现。

## 1. 页面结论

页面统一采用“**问题优先、议题持续、状态可解释、成果可追溯**”框架：

```text
首页：问题输入是第一视觉焦点
推荐确认：理由、职责、风险和用户选择可比较
议题工作区：当前阶段、协作内容、自由追问和推进议题并列
阶段时间线：目标与继承关系高于消息轮次
Skill：能力、职责和边界高于人物头像
资料与成果：来源、确认状态和关联关系可见
设置：风险与数据操作按优先级分组
异常：保留内容、说明原因、提供下一步
```

所有页面共享同一品牌主色、排版、卡片、按钮、风险、恢复、明暗主题、窄屏和无障碍规则。现实支持与思维拓展只使用辅助标记，不形成两套页面。

## 3. 全局导航

手机目标底部导航：

- 首页；
- 议题；
- Skill；
- 资料与成果。

图标与文字同时显示；选中项使用颜色、图形状态和文字字重三重信号；设置不占底部一级位置；键盘打开时不得遮挡输入动作。

宽屏可转换为 Navigation Rail 或侧栏，但不扩展成复杂仪表盘。顶部返回与系统返回语义一致，详情和面板关闭后回到原对象与滚动位置。

## 4. 首页

### 4.1 目标与布局

用户无需先理解 Skill 或多智能体即可表达问题。

```text
顶部：见域简洁标识 + 设置 / 搜索
主标题：现在想看清或推进什么？
多行问题输入
可选方向：现实支持 / 思维拓展 / 两者 / 跳过
可选资料与个人背景入口
主要动作：继续生成建议
恢复卡（如有）
最近活跃议题
最近使用 Skill / 示例问题
底部导航
```

问题输入是首屏最大视觉容器。方向不是必填；资料和个人背景明确“仅在确认后带入”；提交后进入推荐分析 / 确认，不直接开始模型调用。

### 4.2 状态

| 状态 | 视觉承载 |
|---|---|
| 首次空 | 输入 + 少量示例，不用大插画遮挡 |
| 有历史 | 输入仍在第一位，最近议题后置 |
| 输入中 | 保留文本、方向、资料和状态 |
| 推荐准备 | 输入摘要 + 当前分析步骤 |
| 推荐失败 | 原位错误卡 + 重试 / 浏览 Skill / 修改问题 |
| 无合适 Skill | 解释能力缺口，不强行推荐人物 |
| 无执行资格 | 显示开发 / 门禁状态，不伪装可开始 |
| 无 Key | 阻断卡 + 配置入口，保留问题 |
| 离线 | 显示可降级或必须联网原因 |
| 恢复输入 / 推荐 | 恢复卡，不自动提交或开始 |
| 紧急现实危险 | 安全行动优先，普通推荐后置 |

窄屏方向选择可换行；键盘打开后提交 / 取消可达；示例问题读为示例，不读成用户历史。

## 5. Skill 发现与详情

### 5.1 Skill 发现

```text
标题 + 搜索
四类主类型
筛选摘要 / 已选数量
最近使用与收藏（有数据时）
Skill 卡列表或网格
加载 / 无结果 / 失败状态
```

四类主类型：人物视角、专业顾问、任务助手、工作流能力。类型入口同等权重，人物类型不使用更大头像或更亮颜色。

Skill 卡首屏显示：名称、主类型、一句话能力、主价值、单 / 多 Skill 适用方式、最重要的联网 / 资料 / 风险 / 时效 / 人物状态、当前执行资格和主要动作。推荐场景增加“为何匹配”和职责，不显示无上下文推荐分数。

搜索保留查询与筛选；无结果显示冲突条件和清除入口；离线展示本地目录并标记时效；门禁待完成卡不提供误导性“开始”。

### 5.2 Skill 详情

层级：

```text
名称 + 主类型 + 当前状态
一句话能力
适合解决什么 / 不适合什么
输入要求 / 输出形式
单、多 Skill 用法与协作职责
联网、资料、风险、时效
来源、许可与执行资格
人物模拟声明（适用时）
主要动作
```

动作：用于新问题、加入当前议题、替换当前 Skill、收藏。加入和替换都进入确认，不直接调用。

人物 Skill 使用抽象头像或类型图形即可；声明、来源、最后核验日期和高时效状态靠前。统一显示：

> 这是基于公开资料生成的 AI 模拟视角，不代表本人，也不保证复现其当前或完整观点。

特殊 Skill：

- “办公文档助手”不使用 Windows Office 自动控制、宏或桌面文件操作视觉；
- `original-expression-naturalizer` 名称冻结前只使用内部 ID 或“现实沟通文案任务助手”；
- 表达类 Skill 不显示“圆桌整合者”或规避检测职责。

## 6. 推荐确认

### 6.1 页面结构

```text
问题摘要（可编辑）
价值方向（可修改）
推荐单 / 多 Skill 的理由
候选 Skill 与职责
能力重复 / 观点多样 / 核查缺口
资料与个人背景
联网、时效、风险和人物声明
预期输出
将创建 / 继续的议题
确认摘要
底部：返回修改 / 确认开始
```

职责标签：主负责、补充、挑战、核查、整合、工作流、成果构建。重复候选使用差异行，不使用星级、胜率或投票。多 Skill 数量旁显示职责覆盖，避免“越多越好”。

### 6.2 状态

| 状态 | 视觉 |
|---|---|
| 加载 | 问题摘要 + 分析步骤 |
| 待确认 | 决策分组 + 固定主要动作 |
| 用户修改 | 显示变化与待重新确认 |
| 重复冲突 | 原因 + 保留 / 替换 / 分工 |
| 高风险缺口 | 核查 / 专业复核建议 |
| 资料部分失败 | 成功与失败分开，可仅用成功项 |
| 候选资格变化 | 原确认失效，选择仍保留 |
| 提交中 | 防重复，说明创建议题和阶段 |
| 创建失败 | 保留全部选择，说明未创建 / 回滚 |
| 进程重建 | 仍标为待确认，不自动开始 |

窄屏每次突出一个决策区；高风险标题和结论不可折叠到不可见。

## 7. 单 Skill 工作区

```text
顶部：议题标题、活跃 / 归档、当前阶段、更多
阶段上下文：目标、方向、重点资料、预期输出
当前 Skill：名称、职责、状态
协作内容：用户消息、Skill 回答、系统状态
证据 / 分歧 / 行动 / 阶段总结草稿
输入：自由追问
一级动作：停止 / 邀请 Skill / 推进议题
分区：阶段时间线 / 资料 / 成果
```

当前阶段目标高于聊天标题；回答以文档段落和来源块为主，不过度气泡化；邀请其他 Skill 是清晰次级动作；升级多 Skill 后保留历史单 Skill 回答。

运行中稳定保留已完成内容；停止与发送状态明确；失败在原位显示重试 / 忽略。

## 8. 多 Skill 工作区

阵容区使用职责列表，不使用头像堆叠。每个 Skill 显示名称、职责和当前状态，并说明“默认独立回应”。

回答块包含 Skill 名称、职责、运行状态、正文、来源 / 时效 / 风险和后续动作。不显示投票、排行榜或“获胜观点”。

部分成功：成功内容继续显示，失败 Skill 原位说明原因，状态卡汇总成功 / 失败数量，并提供重试失败、忽略、修改阵容或仅基于成功内容继续。不得把不完整结果包装成完整共识。

手机上低频动作可收纳，但自由追问、停止和推进议题始终可达。

## 9. 临时定向回应

配置显示当前阵容、被点名 Skill 的职责、当前问题，以及“本次定向，不会退出多 Skill”。

用户消息显示“定向给：某 Skill”，回复头部显示“临时定向回应”，使用聚焦标记，不更换整页主题。失败只影响该请求，保留阵容和其他历史。

## 10. 显式交叉讨论

配置面板包含：

```text
交叉讨论
选择参与者
讨论焦点（可编辑）
为何推荐这些参与者
一轮讨论边界
结束后由系统整合
确认 / 取消
```

不自动选择全部 Skill；明确只进行一轮；取消不生成空记录。

讨论内容使用观点块、引用、质疑 / 回应关系、条件和证据，不用头像气泡模拟争吵。收束固定包含：共识、分歧、适用条件、明确建议、下一步。结束后不自动创建阶段或正式成果。

## 11. “推进议题”三步面板

### 11.1 入口

“推进议题”是议题工作区一级动作，始终可见。阶段成熟时可增加理由和建议方向，但不遮挡自由追问、不自动打开、不强迫用户完成当前阶段。运行中可暂时禁用提交，但入口和原因仍可见。

### 11.2 第一步：选择推进方向

显示现实支持、思维拓展，并说明不会改变议题主线、不是永久标签。两个方向卡可独立选择，可单选或组合；组合仍只创建一个新阶段。返回或取消不改变当前阶段。

### 11.3 第二步：措施或自定义目标

思维拓展：引入反方意见、查找遗漏视角、检查关键假设、比较不同立场、深入某个问题、自定义目标。

现实支持：明确下一步、形成执行计划、分析执行阻碍、生成成果交付、设置检查节点、自定义目标。

措施卡以动词开头，自定义目标使用多行输入；返回保留选择。

### 11.4 第三步：确认下一阶段摘要

顺序：

1. 下一阶段目标；
2. 方向和措施；
3. 默认继承内容；
4. Skill 阵容；
5. 重点资料；
6. 预期输出；
7. 风险、时效和缺口；
8. 确认后将在原议题创建新阶段。

提交按钮明确“创建下一阶段”。最终确认前不预建节点。创建失败回到原阶段并保留摘要；进程重建查询真实结果，不重复创建。已创建但未运行阶段允许无倒计时撤销，撤销删除空阶段和未提交运行设置并返回上一阶段。

## 12. 阶段时间线

手机使用纵向节点；宽屏可成为侧栏。每个节点显示阶段序号 / 时间、目标、方向、措施、创建原因、继承关系、Skill 快照、重点资料、判断、分歧、行动、成果、失败或停止记录。

| 状态 | 视觉 |
|---|---|
| 当前阶段 | 主色节点 + “当前”文字 |
| 历史阶段 | 中性节点 + 只读标记 |
| 已停止 | 停止图标 + 状态文字 |
| 部分失败 | 警告节点 + 成功 / 失败数量 |
| 创建失败 | 不生成节点，在原阶段显示恢复卡 |
| 归档 | 时间线可读，输入按归档规则 |

响应批次、消息轮次和 `roundIndex` 不显示成阶段节点。查看旧阶段时顶部显示“历史阶段”，主要动作是回到当前阶段；不直接向旧阶段发送消息。

## 13. 资料

议题内分组：已确认资料、待确认推荐、当前阶段重点、历史阶段使用、失败 / 失效 / 已移除但仍被引用。

资料卡显示名称、来源、时效、敏感、联网限制、解析、所属议题 / 阶段和使用状态。

全局资料库包含搜索、按议题 / 阶段 / 来源 / 类型 / 时间筛选、来源关系和“加入当前议题”确认。它不是单纯文件夹树。

失败区分读取失败、解析失败、来源失效、权限、内容过大、联网不可用、时效未核验和敏感资料禁止外部检索。单项失败不阻断成功资料；允许重试、替换、移除、仅用成功项或取消；移除不删除历史引用。

## 14. 成果

议题内成果可包含阶段总结、行动方案、决策记录、知识笔记、交付稿和音频成果。

成果卡显示类型、标题、状态、议题 / 阶段、使用的 Skill、引用资料、确认时间和修订关系。

阶段总结草稿持续显示“草稿，尚未保存为成果”，支持编辑、重新生成、放弃和转化；保存失败保留草稿；跨 Activity 和进程重建持续保留且不自动过期，不能自动升级为正式成果。

正式成果详情显示“已确认保存”、来源链和修订关系。复制不改变状态；导出文件不是新成果；音频派生失败不影响文本成果。

全局“资料与成果”使用一个一级入口和“资料 / 成果”两个页内 Tab，支持搜索、类型 / 议题 / 阶段 / 时间筛选和回到来源。

## 15. 议题列表、归档与关联

议题卡显示标题、当前阶段目标、更新时间、Skill 阵容、运行状态、成果数量和归档状态。列表支持活跃 / 已归档、搜索和筛选。

空状态解释议题是持续容器，主要动作“提出问题”，次要动作“新建议题”。

归档确认显示当前阶段、未完成运行、草稿和成果，并说明归档不删除历史。运行中不预选默认项，由用户明确选择等待当前生成完成后归档，或停止生成并归档。

继续归档议题显示原归档简报、“现在有什么变化”输入、原 Skill / 资料 / 成果和调整确认；恢复不自动创建新阶段。

关联新议题显示来源议题、可编辑简报和用户选择带入的资料 / 成果 / Skill；默认不复制全部聊天；新议题有独立时间线。

## 16. 设置、启动与关于

设置视觉分组：

1. 模型与 API Key；
2. 联网与运行；
3. 隐私与遥测；
4. 本地数据与安全；
5. 导入、导出与恢复快照；
6. 显示与无障碍；
7. 关于见域。

API Key 区分无 Key、可用、验证中、无效、网络异常、限流、存储错误和清空确认。从业务流程进入时显示返回目标。

遥测区分关闭、仅元数据和临时正文调试；正文调试显示范围、期限和风险；云端 Interaction 使用独立确认。

数据与安全按“选择 → 校验 → 差异与冲突 → 恢复快照 → 最终确认 → 写入 / 回退 → 结果”显示；本文不冻结算法和事务。

启动页使用候选 Logo + 见域 + 可选口号，动效一次性且可关闭；长加载转独立状态。关于页包含品牌、短描述、版本、官网（可用后）、隐私、条款、许可、人物与高风险说明和反馈入口，不把迁移写成已完成。

## 17. 全局异常与恢复

运行状态：

```text
准备 → 排队 → 搜索（可选） → 思考 → 流式
→ 成功 / 部分成功 / 全部失败 / 已停止
```

### 17.1 无 Key 与离线

无 Key 阻断调用但保留输入 / 确认；配置后返回原处并由用户再次确认。离线有缓存时保留内容；可降级时说明未核验项；必须联网时使用阻断页；不把离线显示成无结果。

### 17.2 部分成功、全部失败、停止

部分成功保留成功内容和失败清单，提供重试 / 忽略 / 修改阵容 / 基于成功继续。全部失败保留输入，区分无 Key、网络、限流、服务、资料和 Skill 资格，不生成伪成功结果。用户停止使用中性状态，保留已完成内容并显示未完成项。

### 17.3 进程重建

恢复卡说明发生了什么、已保留什么、未完成什么、是否会产生新调用和下一步。待确认流程不自动确认；创建中查询真实结果；流式不把 pending 当正式消息。

### 17.4 紧急现实安全

使用最高优先级安全容器，内容简短、现实行动优先，普通推荐与装饰后置。状态不只使用红色，具体内容遵守安全政策和高风险契约。

## 18. 删除与彻底清除

普通删除显示对象、影响和恢复边界，与归档区分；删除后进入无自动过期回收站，支持恢复或由用户主动彻底清除，容量不足时只提醒。

彻底清除使用独立高风险面板，显示议题、阶段、资料、成果、个人背景和历史引用影响，明确不可恢复，二次确认，默认焦点不放危险按钮；处理中显示不可中断阶段，失败说明到达步骤，历史占位不泄露原文。

## 19. 窄屏、明暗主题与无障碍

窄屏：单列、12dp 边距、48dp 触控目标、标签换行、主要 / 危险按钮纵向、筛选可恢复、时间线纵向、表格转卡片，输入 / 停止 / 推进议题始终可达。

明暗主题保持相同层级、风险、选中、禁用、焦点和操作。暗色以边框和明度差分层，不用大面积高饱和色。

字体放大 200% 时关键文本不截断，底部动作区可增高。横屏保持输入可达，过矮 Bottom Sheet 可切换全屏。

屏幕阅读器进入顺序：页面标题 → 当前议题 / 阶段 / 状态 → 风险或恢复 → 主要内容 → 主要动作 → 次级导航。动态播报只覆盖搜索开始、首个输出、部分失败、完成、停止、恢复和保存成果，不逐字符播报。面板打开后焦点进入标题，关闭后回触发入口。
