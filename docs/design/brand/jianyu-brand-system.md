## 3. 名称与品牌承诺

“见”代表看见、辨认、比较、核查和重新理解；“域”代表问题所处的领域、条件、边界、关系与行动范围。

见域帮助用户：

1. 看见同一问题的不同视角；
2. 看见观点成立的条件与边界；
3. 区分事实、推断和价值判断；
4. 看见可执行、可验证或可继续推进的下一步。

品牌承诺保持克制：

- 帮助用户看得更完整，不声称给出唯一真相；
- 帮助用户形成判断，不替用户作最终决定；
- 把讨论沉淀成行动与成果，不只制造更多回复；
- 明确来源、时效、分歧和不确定性；
- 现实支持与思维拓展属于同一产品、同一议题和同一阶段体系。

## 4. 品牌气质与反关键词

| 气质 | 表现 | 禁止偏移 |
|---|---|---|
| 清醒 | 区分事实、条件、分歧和建议 | 审判式权威腔 |
| 开放 | 容纳不同观点并保留边界 | 无原则堆砌意见 |
| 可信 | 来源、时效、风险和状态可见 | 绝对承诺 |
| 有序 | 议题、阶段、资料、成果清楚 | 复杂流程炫技 |
| 推进 | 结果指向下一步 | 强迫用户推进 |

避免使用：万能、全知、最强、一键解决、权威结论、名人本人、数字分身、替你决定、赛博霓虹、神经网络大脑、全息控制台。

“多智能体”“Agent 编排”等只用于工程或专业说明，不作为普通用户首屏语言。

## 5. 图形隐喻

推荐使用“视域边界与开放中心”：多个视角共同定义更完整的边界，中心留给用户的议题、判断和行动。

可用语汇：

- 开放的框、窗、页和边界；
- 轻微错位的层叠平面；
- 从不同方向接近但不封闭的线；
- 阶段节点与开放终点；
- 留白形成的中心视域。

禁用方向：

| 方向 | 原因 |
|---|---|
| 眼睛或瞳孔 | 容易联想到监控与隐私风险 |
| 大脑和神经网络 | AI 产品同质化，暗示万能大脑 |
| 对话气泡 | 把产品缩减为聊天工具 |
| 头像环 | 把 Skill 缩减为人物列表 |
| 投票、法槌、奖杯 | 暗示多数裁决或权威结论 |
| 罗盘、靶心 | 暗示唯一正确答案 |
| 无限符号 | 暗示无限讨论 |
| 霓虹门户 | 过度科幻，削弱生产力可信感 |

## 6. Logo 与 App Icon 候选

原创候选位于 [`assets/`](./assets/)，均不含第三方图片、图标或字体。

### 6.1 候选 A：开域窗（推荐深化）

三组开放边界共同围合中心视域，表达多种观点共同帮助用户看见问题边界。

优点：

- 小尺寸、单色和反白适配较稳定；
- 可延展为阶段节点与轻量品牌动效；
- 不依赖中文笔画；
- 与“域、窗口、视野”关联直接。

风险：需排查与窗口、取景框和设计软件图标的相似性；极小尺寸应简化层数；禁止循环旋转。

### 6.2 候选 B：域界折页

两个错位折页形成开放边界，强调资料、观点和阶段的展开与对照。

优点：编辑部与知识工作气质强，单色轮廓简洁。风险：可能被误解为电子书或笔记 App，多 Skill 表达较弱。

### 6.3 候选 C：多视线汇聚

三条方向不同的线接近开放中心，表达多视角围绕同一议题。

优点：动态延展较强。风险：可能接近罗盘、眼睛或信号图标，小尺寸稳定性较弱。

### 6.4 取舍

| 维度 | A 开域窗 | B 域界折页 | C 多视线汇聚 |
|---|---:|---:|---:|
| 名称匹配 | 5 | 4 | 4 |
| 小尺寸 | 5 | 4 | 3 |
| 生产力气质 | 5 | 5 | 3 |
| 多视角表达 | 5 | 3 | 5 |
| 单色适配 | 5 | 5 | 3 |
| 推荐 | **优先深化** | 保留 | 局部语言备选 |

评分只用于设计取舍，不代表商标可注册性。PR08-D 不锁定最终 Logo。

## 7. 品牌组合规范

品牌组合可包含图形、“见域”和可选口号。当前不制作依赖特定字体轮廓的正式字标。

| 场景 | 组合 |
|---|---|
| App Icon | 仅图形 |
| 启动页 | 图形 + 见域；口号可选 |
| 官网导航 | 图形 + 见域横向组合 |
| 关于页 | 图形 + 名称 + 口号 + 产品短描述 |
| 小于 24px | 简化单色图形 |

以图形中心开口宽度 `x` 为基准：四周安全空间不小于 `1x`，图形与名称间距约 `0.75x`。

建议最小尺寸：图形 20px、横向组合 24px 高、带口号组合 48px 高。必须准备深色单色、白色反白、品牌主色和高对比版本。渐变和阴影不能成为识别前提。

## 8. App Icon

- 按 Android Adaptive Icon 的前景 / 背景分层设计；
- 前景保留核心轮廓，背景优先单一品牌色；
- 在圆形、圆角方形和水滴蒙版下保持主要轮廓；
- 16～24px 使用简化版，通知图标提供纯色剪影；
- 不放“见域”文字、口号、人物头像、Skill 数量或“AI”；
- 不依赖玻璃拟态、发光或粒子；
- 当前 SVG 只是构图探索，不能直接当作商店最终图标。

## 9. 启动页与关于页

### 9.1 启动页

结构：图形、见域、可选口号。允许 240～360ms 的一次性边界展开；减少动效时静态显示；长加载使用独立可解释状态，不让 Logo 无限动画。

启动页不展示尚未实现的官网、账号同步或云端能力。

### 9.2 关于页

至少包含：

- 品牌图形、名称与口号；
- “面向个人的多智能体思考与行动工作台”短描述；
- 版本与构建信息；
- 官网（正式可用后再启用）；
- 隐私、条款、开源许可和第三方声明；
- AI 辅助、用户保留最终决定权的边界；
- 人物模拟与高风险能力说明入口；
- 反馈入口。

关于页不承担 API Key、遥测或数据恢复的主要职责，也不把目标迁移写成当前事实。

## 10. 品牌文案语气

规则：先说明发生了什么，再说明用户可以做什么；对不确定信息使用“可能、基于当前资料、尚未核验”；对错误提供恢复路径；对推荐说明理由和取舍；对推进使用邀请式语言。

示例：

- 推荐：“建议加入核查能力，因为当前结论依赖近期政策。”
- 分歧：“这两种建议依赖不同前提，暂不应合并为单一结论。”
- 推进：“你可以继续追问，也可以为议题建立下一阶段目标。”
- 失败：“已保留成功内容。可重试失败 Skill，或仅基于现有结果继续。”

禁止把 AI 描述为替用户作出最佳决定、把多人意见包装成权威共识，或把“下一轮”作为目标产品正式入口。

## 11. 两类价值的品牌关系

现实支持与思维拓展必须共享同一 Logo、主色、字体、页面骨架、议题、阶段、Skill 卡、资料、成果、风险和来源体系。

仅通过轻量辅助标记区分：

- 现实支持：路径、检查点和落地线；
- 思维拓展：开放边界、分歧和视角线；
- 两者组合：并列两枚小型方向标记，不产生第三套主题。

不得为两类价值建立不同页面壳、不同主导航或两个首页入口。

## 12. Skill 品牌表达

四类 Skill 使用统一卡片和图标网格：

| 类型 | 图形语义 | 禁止 |
|---|---|---|
| 人物视角 | 视角、引号、观察框 | 真人肖像作为唯一识别 |
| 专业顾问 | 指南、标尺、核查框 | 证书式权威暗示 |
| 任务助手 | 工具、编辑、交付框 | 无人值守自动执行暗示 |
| 工作流能力 | 路径、阶段、检查点 | 无限循环图形 |

人物 Skill 不建立“名人专区”，并完整显示：

> 这是基于公开资料生成的 AI 模拟视角，不代表本人，也不保证复现其当前或完整观点。

人物姓名、肖像、商标和独特表达风格需独立核验。

特殊 Skill：

- `office-document-productivity` 的正式中文定位为“办公文档助手”，不得暗示控制 Windows Office、宏、桌面文件系统或复杂格式保真；
- `original-expression-naturalizer` 的用户侧中文名称为“去AI化助手”；目录、详情、推荐确认、首次调用确认和成果导出说明必须就近显示“让真实内容更像你本人表达，不用于规避检测或伪造事实”；
- 表达类 Skill 不使用“不可检测”等语言，也不负责统一圆桌观点或掩盖分歧。
