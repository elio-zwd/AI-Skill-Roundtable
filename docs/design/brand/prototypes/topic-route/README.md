# 见域「议题航线」HTML 视觉原型

> 本目录仅用于 PR08-D 视觉方向比较，不代表 Android 功能、正式品牌、最终文案或产品行为已经实现。

## 原型内容

`index.html` 在一个页面中提供三套可切换方案：

1. **A 静轨工具版**：生产力工具优先，航线最克制；
2. **B 航点平衡版**：品牌与工具平衡，作为下一轮深化候选；
3. **C 展域空间版**：路径和空间感最强，探索多端扩展能力。

每套方案均覆盖：

- 首页；
- 多 Skill 议题工作区；
- “推进议题”三步流程；
- 阶段时间线；
- 资料与成果。

页面支持：

- 方案切换；
- 页面切换；
- 推进议题步骤切换；
- 明暗主题；
- 手机与桌面响应式浏览。

## 查看方式

### 方式一：本地打开

下载本目录后，直接用浏览器打开 `index.html`。页面不依赖构建命令、外部脚本、外部字体或图片资源。

### 方式二：GitHub HTMLPreview

可使用 HTMLPreview 服务加载 GitHub 上的 `index.html`。这只是第三方预览方式，不属于仓库正式部署或官网方案。

## 设计边界

- “议题航线”只是辅助理解议题演进的视觉语言，不替代正式术语；
- 正式入口仍为“推进议题”；
- 流程仍严格保持三步：方向 → 措施或自定义目标 → 确认下一阶段摘要；
- 只有第三步确认后才创建新阶段；
- 一个议题保持一条已确认主线；
- 未确认方向只作为候选，不形成正式分支；
- 需要独立主线时，由用户显式创建关联新议题；
- 现实支持与思维拓展属于同一产品，可组合和切换；
- 页面中的文字、颜色和图形均为讨论样例，不能直接视为最终 PR08-D 结论。
