## 2. 已冻结、不随视觉参考图回退的产品决定

视觉校准不得覆盖已经批准的产品规则：

- 标题使用 `推荐角色`，不得恢复参考图中的 `为你推荐`；
- 固定编辑精选为：纳瓦尔 → 理查德·费曼 → 纳西姆·塔勒布；
- 分类为 `全部 / 思考方法 / 职业成长 / 研究学习 / 产品创造 / 沟通表达 / 办公事务 / 生活工具`；
- 44 项 Official Skill 都可发现；
- 真人角色可使用稳定人物头像并标记 `AI 模拟角色`；
- 功能型角色不得为了模仿参考图而生成或伪造真人头像，应使用稳定非真人身份视觉；
- UI-01 的最终 `对话 / 角色 / 资料 / 我的` 底栏仍是外部依赖，UI-02 不私建第二套底栏。

## 3. A 页（全部）主要差异

### 3.1 顶部结构过高

参考 A 的标题、说明和右上动作区更紧凑；当前实现把 `收藏 / 筛选` 放在说明同行，使标题区整体高度明显放大，首屏内容向下挤压。

校准目标：

- 标题与动作同一主行；
- 说明作为标题下方弱文案；
- 收藏保持独立热区；
- 筛选保持可达，但视觉重量低于标题；
- 搜索框紧接标题区，不额外制造大段留白。

### 3.2 推荐 Hero 缺少主视觉层级

参考 A 的 Hero 是整页最强视觉锚点：大幅人物视觉占据左侧，右侧是名称、摘要、标签和主动作，整体使用弱紫/蓝容器。

当前实现是通用白色 Card + 小型圆/方头像，人物视觉占比太低，与下面普通卡片差异不足。

校准目标：

- Hero 使用淡色身份背景；
- featured 真人头像放大为左侧主视觉区域；
- 名称/摘要/查看动作形成清晰纵向层级；
- 仍保留收藏独立点击；
- 不显示内部技术标签。

### 3.3 两张次级推荐卡结构不符

参考 A 两张次卡是横向视觉卡：人物视觉在左，文字在右；当前实现复用了通用竖向 GridCard，导致人物很小、白卡面积大、信息层级与参考图不同。

校准目标：专用紧凑推荐卡，维持双列，但每张卡采用“左视觉 + 右信息”。

### 3.4 暴露内部 `domainTags`

当前实际截图直接显示如 `career_workplace`、`creator_business...` 的内部 token。这属于实现问题，不是视觉偏好。

校准目标：UI-02 卡片不得直接输出 raw `domainTags`；只显示用户可理解的发现分类、角色类型、`AI 模拟角色` 等产品语义标签。

### 3.5 全部角色列表视觉应更连续

参考 A 的“全部角色”更接近一个连续白色列表容器，行间弱分隔；当前实现每行都是独立浮动 Card。

第一轮优先降低独立 Card 的浮层感；若第二轮截图仍差异明显，再收敛成单一列表容器。

## 4. B 页（具体分类）主要差异

### 4.1 分类说明卡缺少品牌装饰层

参考 B 使用弱紫描边/底色和右侧抽象网络节点装饰，当前实现是单一大色块。

第一轮目标：保持低干扰，同时增加轻量节点/连线品牌纹理，不能影响文字可读性。

### 4.2 双列角色卡缺少上半部主视觉

这是当前与参考 B 最大差异。

参考 B 每张卡约上半部为人物/身份视觉，下半部才是名称、摘要和标签；当前功能角色只显示一个很小的文字方块，整张卡大部分是文字和空白。

校准目标：

- 真人角色：稳定头像扩展为卡片上方大视觉；
- 功能角色：使用大面积、确定性的非真人身份色块 + 简短身份字标；
- 禁止为功能角色生成虚构人脸；
- 卡片下半部保留名称、短摘要和收藏；
- 双列宽度与参考图接近，大字体/窄屏仍允许降单列。

## 5. 功能验收补充事实

本轮截图确认以下 UI-02 页面能力已真实显示：

- 正确 UI-02 入口可以显示搜索、8 个分类 Chip、推荐区；
- `生活工具` 显示说明和 5 个主发现角色；
- UI-02 搜索 `meeting-to-action` 能命中“会议纪要与行动项助手”；
- 真人详情与功能角色详情均可打开；
- 空搜索状态正常。

但会话动作尚未完成手工闭环：

- `开始新对话` 本轮未稳定展示进入 Dialog 后的 participant 画面；
- `增加到当前会话` 因当时没有当前会话而处于 disabled；
- recent 出现只能作为部分证据，不能代替真实 participant / Dialog 验收。

下一轮必须继续验证真实会话桥。

## 6. 第一轮视觉校准范围

本轮只做以下最小范围：

1. 新 UI-02 专用 Screen 与视觉组件，避免继续复用 legacy Catalog Screen 的旧视觉/旧 Dialog 状态；
2. 紧凑 Header；
3. A 页大 Hero；
4. A 页横向双列次级推荐；
5. B 页带大视觉区的双列卡；
6. 分类说明卡轻量品牌纹理；
7. 不再显示 raw `domainTags`；
8. 保留搜索、分类、收藏、筛选、recent、详情导航和所有既有产品语义。

不在本轮修改：

- UI-01 底栏；
- Room Schema；
- Gemini transport；
- OfficialSkillCatalog 44 项事实；
- 已批准分类/featured 决策。
