# 文本资料编辑页候选

> 图片类型：完整新增 / 编辑二级页面
>
> 输出：1 张 1440 × 3200 Android 竖屏图片

## 1. 页面布局

遵循[共享视觉基线](../共享/jianyu-shared-visual-baseline.md)。

- 顶部左侧关闭；
- 标题：`添加文本资料`
- 右侧文字按钮：`保存`

表单：

1. 类型分段控件：`摘录`（选中）/ `文本笔记`
2. 标题：`STM32 项目复盘摘录`
3. 内容：大号多行编辑器，展示约 8～10 行真实中文示例；
4. 来源：`项目复盘文档`
5. 来源日期：`2026-08-29`
6. 标签：`STM32`、`项目复盘`
7. `标记为敏感资料` 开关关闭。

编辑器白底、大圆角、淡紫灰边框；底部显示弱字符计数。

## 2. 底部操作

- `取消`
- 蓝色主按钮：`保存到资料`

弱说明：`资料不会自动成为成果。`

## 3. 不要生成

- 自动保存为成果；
- 自动生成用户个人背景；
- Markdown 工程工具栏铺满屏幕；
- 代码 IDE 风格；
- 无法取消的自动保存。
