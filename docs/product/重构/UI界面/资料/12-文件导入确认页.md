# 文件导入确认页候选

> 图片类型：系统文件选择后的 App 内完整确认页面
>
> 输出：1 张 1440 × 3200 Android 竖屏图片

## 1. 当前文件

- `嵌入式转岗学习路线.pdf`
- PDF，24 页，3.8 MB
- 来源：本地文件

## 2. 页面布局

遵循[共享视觉基线](../共享/jianyu-shared-visual-baseline.md)。

- 顶部左侧关闭；
- 标题：`确认导入资料`
- 大型文件预览卡：PDF 图标、文件名、类型、大小和第一页弱预览；
- 输入框：`资料名称`，预填去除扩展名的标题；
- 可选文本框：`备注`
- 可选标签 Chip：`学习路线`、`嵌入式`；
- 勾选：`将文件来源保留在资料信息中`，默认勾选；
- 开关：`标记为敏感资料`，默认关闭；
- 弱说明：`导入不会自动把文件发送给任何 Skill 角色。`

## 3. 底部操作

- `取消`
- 蓝色主按钮：`添加到资料`

## 4. 不要生成

- “上传到云端”默认勾选；
- 自动选择全部角色；
- 个人背景类型；
- 导入后自动生成成果；
- 解析成功保证。
