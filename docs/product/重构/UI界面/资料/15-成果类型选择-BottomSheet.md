# 成果类型选择 Bottom Sheet 候选

> 图片类型：保存成果流程中的轻模态 Bottom Sheet
>
> 输出：1 张 1440 × 3200 Android 竖屏图片

## 1. 背景

背景为“保存为成果”Sheet 或成果编辑页，使用较轻 Scrim。遵循[共享视觉基线](../共享/jianyu-shared-visual-baseline.md)。

## 2. 选项

- 标题：`选择成果类型`
- 副说明：`类型只用于整理，不改变成果内容`

单列大行选项：

1. `行动方案`
   - 适合步骤、计划、里程碑；
2. `判断与决策`
   - 适合结论、权衡和决策记录；
3. `知识笔记`
   - 适合学习总结和结构化知识；
4. `沟通文稿`
   - 适合邮件、发言、说明和文案；
5. `其他`
   - 使用通用文档图标。

当前选中 `行动方案`，右侧蓝色 Check。

## 3. 视觉规则

- 每种类型使用低饱和圆角图标容器；
- 不用五种高饱和大色块；
- 不显示“系统自动判断类型”；
- Sheet 底部按钮：`完成`。
