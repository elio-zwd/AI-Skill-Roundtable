# 保存为成果 Bottom Sheet 候选

> 图片类型：从【对话】页面触发的 Modal Bottom Sheet
>
> 输出：1 张 1440 × 3200 Android 竖屏图片

## 1. 触发背景

背景使用已选定【对话】页面：用户点击规划教练消息下方 `保存为成果`。消息保持可见，背景使用 35% Scrim。

## 2. Sheet 外观

- 白色；
- 顶部大圆角；
- 中央 Handle；
- 标题：`保存为成果`
- 右上关闭按钮；
- 遵循[共享视觉基线](../共享/jianyu-shared-visual-baseline.md)。

## 3. 表单内容

### 成果标题

输入框预填：`3 个月嵌入式转岗行动方案`

### 成果类型

横向单选 Chip：

- `行动方案`（蓝色选中）
- `判断与决策`
- `知识笔记`
- `沟通文稿`

### 保存内容预览

白色弱描边卡显示当前准备保存的消息摘要，顶部写：

`来自规划教练的回复`

正文只展示 4～6 行并使用渐隐，底部入口：`查看完整内容`。

### 来源关系

显示：

- 当前会话标题；
- 规划教练头像与姓名；
- 保存时间；
- 开关 / 勾选：`保留来源会话关系`，默认勾选。

## 4. 底部操作

- 次按钮：`取消`
- 主按钮：`确认保存`

按钮下弱灰说明：

`确认后，这段内容才会成为正式成果。`

## 5. 不要生成

- 默认自动保存；
- “AI 已替你确认”；
- 没有取消入口；
- 把整段消息缩成无法阅读的小字；
- 真实外部发布 / 分享动作。
