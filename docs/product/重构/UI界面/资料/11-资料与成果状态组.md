# 【资料】与【成果】页面状态组候选

> 图片类型：同页面多状态对比
>
> 输出：优先生成 4 张独立图片；工具受限时生成一张四分栏状态板

## 1. 共享布局

以主页面候选 A“资料 / 成果”双 Tab 为基础，遵循[共享视觉基线](../共享/jianyu-shared-visual-baseline.md)。底部【资料】选中。

## 2. 状态一：资料为空

- 当前资料 Tab；
- 线性文件夹插图，浅蓝紫；
- 标题：`还没有资料`
- 说明：`添加文件、链接或文本，之后可以选择带入对话。`
- 主按钮：`新增资料`
- 次入口：`了解资料如何使用`

## 3. 状态二：成果为空

- 当前成果 Tab；
- 线性星标文档插图，浅薄荷；
- 标题：`还没有保存的成果`
- 说明：`在对话中确认保存后，方案、笔记和文稿会出现在这里。`
- 主按钮：`返回对话`
- 不提供“自动生成成果”。

## 4. 状态三：搜索无结果

- 搜索词：`蓝牙音频`
- 标题：`没有找到相关内容`
- 说明：`尝试更换关键词或清除筛选。`
- 按钮：`清除筛选`
- 保留资料 / 成果当前 Tab 和搜索框。

## 5. 状态四：资料读取失败

- 标题：`资料暂时无法读取`
- 说明：`请稍后重试。现有本地资料不会因此被删除。`
- 主按钮：`重试`
- 次入口：`查看已保存成果`
- 不显示内部异常、路径或堆栈。

## 6. 比较重点

- 资料空状态与成果空状态是否一眼可区分；
- 文案是否清楚表达“用户确认”；
- 错误状态是否克制；
- 状态页是否保持与内容页一致的底部导航和顶部结构。
