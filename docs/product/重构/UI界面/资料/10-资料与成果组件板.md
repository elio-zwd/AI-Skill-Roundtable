# 【资料】与【成果】组件板候选

> 图片类型：组件样式板
>
> 输出：1 张 1440 × 3200 浅色 Android UI 组件板

## 1. 画板结构

- 标题：`资料与成果组件`
- 冷紫灰背景；
- 分区展示，不画开发标尺；
- 遵循[共享视觉基线](../共享/jianyu-shared-visual-baseline.md)。

## 2. 必须展示

### 类型图标

- PDF；
- Word；
- 网页链接；
- 文本摘录；
- 行动方案；
- 判断与决策；
- 知识笔记；
- 沟通文稿。

### 卡片

- 资料单列卡；
- 资料紧凑横卡；
- 成果摘要卡；
- 来源会话卡；
- 敏感资料卡；
- 已选资料行。

### 状态与标签

- `资料` / `成果` 类型标签；
- `本地资料`；
- `已保存成果`；
- `敏感资料`；
- `用于 2 个会话`；
- 上传中进度；
- 上传失败；
- 选中 Check。

### 控件

- 资料 / 成果分段控件；
- 类型筛选 Chip；
- 搜索框；
- `+ 新增资料` 胶囊按钮；
- `确认保存` 主按钮；
- 三点菜单；
- 多选复选框。

## 3. 要求

- 资料和成果必须通过文字 + 图标共同区分；
- 不用鲜艳文件类型品牌色；
- 不出现个人背景；
- 不出现云容量、价格或共享人数；
- 中文标题完整、无伪文字。
