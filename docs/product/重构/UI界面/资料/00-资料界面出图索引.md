# 【资料】界面出图索引

> 状态：候选方案，待用户看图选择
>
> 一级导航与页面标题均使用【资料】；页面内部同时管理资料与成果。

## 1. 不变的对象边界

- 资料：用户选择带入对话的文件、链接、摘录、文本和来源；
- 成果：用户明确确认保存的判断、方案、笔记、文稿等可复用输出；
- 普通 Skill 角色回复和自动草稿不会自动成为成果；
- 个人背景不属于本页面，归入【我的】；
- 资料与成果可以在同一一级页面中管理，但必须保持可辨认的对象类型。
