# 【资料】主页面候选 B｜总览分区

> 图片类型：完整一级页面候选图
>
> 输出：1 张 1440 × 3200 Android 竖屏图片
>
> 目的：验证用户是否需要先看到资料与成果的整体概况，再进入具体列表。

## 1. 必须继承

遵循[共享视觉基线](../共享/jianyu-shared-visual-baseline.md)。底部导航完整显示“对话 / 角色 / 资料 / 我的”，当前【资料】蓝色选中。

## 2. 页面布局

### 顶部栏

- 标题：`资料`
- 副标题：`你的依据与沉淀`
- 右侧：搜索图标、紫色 `+`

### 双概览卡

首屏顶部横向两张等权卡片：

1. `资料`
   - 数量：`4`
   - 说明：`文件、链接与摘录`
   - 浅蓝紫背景；
   - 文件夹线性图标；
   - 文字入口：`查看全部`。
2. `成果`
   - 数量：`4`
   - 说明：`方案、笔记与文稿`
   - 极浅薄荷背景；
   - 星标 / 文档线性图标；
   - 文字入口：`查看全部`。

两张卡同尺寸、同权重，不使用“完成率”或增长数据。

### 最近使用的资料

标题：`最近使用的资料`，右侧 `全部资料`

横向两张卡：

- `嵌入式转岗学习路线.pdf`
- `招聘岗位能力要求汇总`

卡片显示类型图标、标题、更新时间和 `用于 2 个会话`，整卡可点击。

### 最近保存的成果

标题：`最近保存的成果`，右侧 `全部成果`

单列两张较宽成果卡：

- `3 个月嵌入式转岗行动方案`
- `嵌入式岗位能力差距清单`

成果卡显示类型、来源会话、保存时间和两行摘要；使用很淡的薄荷或薰衣草边框。

### 底部提示卡

一张低强调说明卡：

`只有你明确保存的内容才会成为成果。`

左侧小型星标图标，背景极浅紫白。

## 3. 视觉重点

- 资料与成果在总览上平级；
- 概览卡不能像统计仪表盘；
- 最近内容以真实阅读对象为主，不显示图表；
- 页面整体仍为内容库，而不是首页 Dashboard。

## 4. 不要生成

- 饼图、折线图、增长百分比；
- 存储空间促销；
- 自动成果数量；
- 个人背景卡；
- 资料与成果混成相同图标和相同标签。

## 5. 用户主要比较点

- 概览是否比 Tab 更容易理解；
- 进入完整列表是否多了一层；
- 最近资料与最近成果是否都能在首屏出现；
- 总览卡是否有不必要的 Dashboard 感。
