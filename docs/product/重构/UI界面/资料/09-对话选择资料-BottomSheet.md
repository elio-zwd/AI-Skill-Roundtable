# 对话选择资料 Bottom Sheet 候选

> 图片类型：与对话 Composer 联动的选择 Bottom Sheet
>
> 输出：1 张 1440 × 3200 Android 竖屏图片

## 1. 触发背景

用户在【对话】页点击 `+` → `选择资料`。背景保留对话消息和输入区，使用较轻的 Scrim；底部导航仍可见但不可交互。

## 2. Sheet

遵循[共享视觉基线](../共享/jianyu-shared-visual-baseline.md)。

- 标题：`选择资料`
- 副说明：`只会把你确认的资料用于这次对话`
- 搜索框：`搜索资料`
- 右上关闭按钮；
- Sheet 高度约屏幕 68%，内部列表滚动。

## 3. 快速筛选

Chip：

- `最近使用`（选中）
- `PDF`
- `链接`
- `文本`

## 4. 资料列表

显示四个固定示例资料。每行：

- 类型图标；
- 标题；
- 来源 / 格式；
- 最近使用时间；
- 右侧复选框。

当前勾选：

- `嵌入式转岗学习路线.pdf`
- `招聘岗位能力要求汇总`

选中行使用极浅蓝背景和蓝色 Check。

若资料标记为敏感，行内显示琥珀色弱标签 `敏感资料`，但本示例图只给 `面试准备资料清单.docx` 显示该标签，不默认勾选。

## 5. 底部确认

- 左侧：`已选择 2 项`
- 右侧蓝色主按钮：`用于本次对话`
- 下方弱提示：`资料不会自动发送给未选择的角色。`

## 6. 不要生成

- 一键选择全部敏感资料；
- 默认把所有资料发送给全部角色；
- 个人背景；
- 成果混入资料选择列表；
- 模型参数。
