# 链接资料编辑页候选

> 图片类型：完整新增 / 编辑二级页面
>
> 输出：1 张 1440 × 3200 Android 竖屏图片

## 1. 页面布局

遵循[共享视觉基线](../共享/jianyu-shared-visual-baseline.md)。

- 顶部左侧关闭；
- 标题：`添加链接资料`
- 右侧文字按钮：`保存`

表单：

1. `链接地址`
   - 示例：`https://example.com/embedded-roadmap`
   - 右侧粘贴图标；
2. `资料名称`
   - `招聘岗位能力要求汇总`
3. `来源名称`
   - `示例招聘网站`
4. `备注`
   - 多行，可为空；
5. `标记为敏感资料`
   - 开关关闭。

链接预览卡显示域名、页面标题和两行摘要，占位图只用线性网页图标，不生成随机网站品牌 Logo。

## 2. 底部说明

`保存链接不会自动读取或发送网页内容；实际使用时仍由你确认。`

底部主按钮：`保存链接资料`

## 3. 不要生成

- 真实登录态网页；
- 未授权抓取成功提示；
- 自动发送全部网页内容；
- 完整 Cookie 或 Token；
- 个人背景字段。
