# 【资料】主页面候选 C｜统一内容流

> 图片类型：完整一级页面候选图
>
> 输出：1 张 1440 × 3200 Android 竖屏图片
>
> 目的：验证按最近活动统一查找资料和成果是否更高效，同时保持类型边界。

## 1. 必须继承

遵循[共享视觉基线](../共享/jianyu-shared-visual-baseline.md)。底部导航完整显示“对话 / 角色 / 资料 / 我的”，当前【资料】蓝色选中。

## 2. 页面状态

当前筛选为 `全部`，按最近更新排序。

## 3. 页面布局

### 顶部栏

- 标题：`资料`
- 右侧：搜索、筛选、紫色新增图标
- 下方搜索框：`搜索资料与成果`

### 类型筛选

横向 Chip：

- `全部`（蓝色选中）
- `资料`
- `成果`
- `PDF`
- `链接`
- `文稿`

### 最近内容时间流

标题：`最近内容`

按“今天 / 昨天 / 更早”分组，使用单列混合列表。

每项左侧有明确类型色条和图标：

- 资料项显示蓝色小标签 `资料`；
- 成果项显示绿色或紫色小标签 `成果`；
- 标题、两行摘要、时间和来源；
- 资料显示文件类型 / 网页来源；
- 成果显示 `保存自：如何把复杂目标拆成可执行计划？`；
- 右侧三点菜单。

示例顺序：

1. 今天：`3 个月嵌入式转岗行动方案`（成果）；
2. 今天：`嵌入式转岗学习路线.pdf`（资料）；
3. 昨天：`招聘岗位能力要求汇总`（资料）；
4. 昨天：`嵌入式岗位能力差距清单`（成果）；
5. 更早：`STM32 项目复盘摘录`（资料）。

### 新增入口

紫色胶囊 FAB：`+ 新增资料`

该入口只新增资料，不直接创建成果；成果从对话或已有内容明确保存。

## 4. 视觉重点

- 统一流提高“最近内容”查找效率；
- 每项必须一眼看出是资料还是成果；
- 类型标签使用文字 + 图标，不能只靠颜色；
- 时间分组样式参考对话页会话记录 Drawer；
- 内容流保持阅读感，不做社交动态 Feed。

## 5. 不要生成

- 点赞、评论、分享计数；
- 把资料与成果使用同一类型标签；
- 自动生成成果的提示；
- 个人背景；
- 文件夹树。

## 6. 用户主要比较点

- 混合列表是否提高效率还是增加认知负担；
- 类型标签是否足够清楚；
- 用户是否仍能快速只看资料或只看成果；
- “新增资料”是否与成果创建方式清楚区分。
