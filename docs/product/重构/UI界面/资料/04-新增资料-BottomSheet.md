# 新增资料 Bottom Sheet 候选

> 图片类型：带【资料】页面背景的 Modal Bottom Sheet
>
> 输出：1 张 1440 × 3200 Android 竖屏图片

## 1. 触发背景

背景使用【资料】主页面候选 A，当前在资料 Tab。用户点击 `+ 新增资料`，背景覆盖 35% 左右黑色 Scrim。

## 2. Sheet 外观

遵循[共享视觉基线](../共享/jianyu-shared-visual-baseline.md)：白色、顶部大圆角、中央 Handle、右上关闭按钮。

- 标题：`新增资料`
- 副说明：`选择资料来源，添加后仍由你决定是否带入对话`

## 3. 三个主要入口

### 上传文件

- 浅蓝圆角图标容器，回形针 / 文件图标；
- 说明：`PDF、Word、文本等本地文件`
- 右侧 Chevron。

### 添加链接

- 浅薄荷图标容器，链条 / 地球图标；
- 说明：`保存网页地址与来源信息`
- 右侧 Chevron。

### 粘贴文本

- 浅薰衣草图标容器，文本图标；
- 说明：`添加摘录、笔记或一段参考内容`
- 右侧 Chevron。

三个入口使用大行高和淡分割线，不做彩色大按钮。

## 4. 底部说明

浅灰信息卡：

`资料是对话的输入与依据，不会自动成为成果。`

第二行：

`敏感资料需要你在使用时再次确认。`

## 5. 不要生成

- “个人背景”入口；
- “自动发送给所有角色”；
- 云盘授权和第三方登录；
- 相机扫描、录音等当前没有决定的入口；
- 上传成功的虚假承诺。
