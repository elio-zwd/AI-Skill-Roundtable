# 成果详情页候选

> 图片类型：完整二级页面
>
> 输出：1 张 1440 × 3200 Android 竖屏图片

## 1. 当前对象

- 标题：`3 个月嵌入式转岗行动方案`
- 类型：行动方案
- 保存时间：今天 10:35
- 来源会话：`如何把复杂目标拆成可执行计划？`
- 状态：用户已确认保存

## 2. 顶部栏

- 左侧返回箭头；
- 标题：`成果详情`
- 右侧：编辑图标、更多菜单；
- 二级页面不显示底部一级导航。

## 3. 成果头部

遵循[共享视觉基线](../共享/jianyu-shared-visual-baseline.md)。

白色大圆角卡：

- 浅薄荷星标 / 文档图标；
- 大标题；
- 绿色弱 Chip：`已保存成果`
- 类型：`行动方案`
- 时间；
- 不显示“AI 已认证”或完成百分比。

## 4. 正文区

近白大卡片，支持 Markdown 阅读排版：

- `目标`
- `12 周行动计划`
- `每周投入时间`
- `里程碑`
- `风险与调整方式`

展示两到三个段落和列表，使图片能判断正文的标题、列表、分割和留白。

## 5. 来源关系

标题：`来自这段对话`

会话卡显示：

- 会话标题；
- 保存成果时参与的“规划教练”“系统思考者”两个头像；
- 保存时间；
- 按钮：`打开来源会话`。

## 6. 底部操作

固定或贴底操作条：

- `复制`
- `继续编辑`
- `导出`
- `更多`

删除成果位于更多菜单并使用红色文字，需要确认。

## 7. 不要生成

- 未确认草稿状态；
- 自动评分、完成率；
- 把角色回复原样冒充用户最终结论；
- 资料的文件页数、大小等元数据；
- 成果自动发布或外部分享成功状态。
