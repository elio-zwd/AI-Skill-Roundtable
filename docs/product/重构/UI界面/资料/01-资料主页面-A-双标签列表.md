# 【资料】主页面候选 A｜双标签列表

> 图片类型：完整一级页面候选图
>
> 输出：1 张 1440 × 3200 Android 竖屏图片
>
> 目的：验证最直接的“资料 / 成果”双 Tab 是否清楚易用。

## 1. 必须继承

遵循[共享视觉基线](../共享/jianyu-shared-visual-baseline.md)。底部导航为“对话 / 角色 / 资料 / 我的”，【资料】蓝色选中。

## 2. 当前页面状态

- 当前 Tab：`资料`；
- 共 4 份资料；
- 搜索为空；
- 默认排序：最近更新；
- 没有正在上传的文件。

## 3. 页面布局

### 顶部栏

- 标题：`资料`
- 副标题：`管理带入对话的依据与已保存成果`
- 右侧：搜索图标、紫色圆角 `+` 图标

### 双 Tab

顶部栏下方为白色圆角分段控件：

- `资料  4`（蓝色选中）
- `成果  4`

选中态使用浅蓝背景和蓝色文字；未选中态灰蓝文字。数字使用小号弱强调，不做通知红点。

### 工具行

- 左侧筛选 Chip：`全部类型`
- 第二个 Chip：`最近更新`
- 右侧线性筛选图标

### 资料列表

单列大圆角卡片，显示四项固定资料。

每张卡包含：

- 左侧文件类型圆角 Icon Container；
- 标题；
- 类型与大小 / 来源；
- 添加或更新时间；
- 使用状态，例如 `用于 2 个会话`；
- 右侧三点菜单；
- 最多两个来源 / 标签 Chip。

类型颜色保持低饱和：

- PDF：浅红灰，不用鲜红大块；
- 链接：浅蓝；
- 文本：浅薰衣草；
- Word：浅蓝紫。

首项 `嵌入式转岗学习路线.pdf` 使用极浅蓝选中感，表示最近打开，不表示已自动带入当前会话。

### 悬浮新增按钮

右下、底部导航上方使用紫色圆形或胶囊 FAB：

- `+ 新增资料`
- 不遮挡列表内容；
- 与顶部 `+` 只保留一个明显主入口，图片中优先使用胶囊 FAB，顶部右侧可只保留搜索和筛选。

## 4. 成果 Tab 的可比要求

本图只展示资料 Tab，但分段控件必须让用户清楚成果在同一页面。后续若补成果态，复用同一列表结构，成果卡显示类型、来源会话和保存时间。

## 5. 不要生成

- “资料与成果”额外中间标题；
- 个人背景；
- 自动上传到所有角色的开关；
- 文件夹层级树或桌面文件管理器；
- 云盘容量营销；
- 把普通聊天消息标为成果。

## 6. 用户主要比较点

- 双 Tab 是否最易理解；
- 卡片信息是否过多；
- FAB 与顶部动作是否重复；
- 成果入口是否足够可见。
