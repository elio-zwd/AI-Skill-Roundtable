# 见域一级页面信息架构初稿

> 文档状态：初稿，待用户审查
>
> 用途：集中整理见域一级页面及其主要能力，作为后续 UI 重构的讨论底稿。
>
> 重要说明：本文不是定稿。当前按【对话 / 角色 / 资料 / 我的】四个一级名称整理内容，尚未完成用户审查，也不覆盖 ADR-009 和 `docs/product/` 中的当前正式产品规范。

## 1. 当前讨论目标

本轮只讨论与【对话】同级的主要页面，以及各主要页面直接承载的核心能力。

暂不展开：

- 具体详情页布局；
- Dialog、Bottom Sheet、Drawer 等交互形态；
- 空状态、错误状态和加载状态；
- 导航 Route、数据模型和实现方案；
- 视觉样式与组件细节。

## 2. 一级导航初稿

当前暂定四个一级入口：

1. 【对话】
2. 【角色】
3. 【资料】
4. 【我的】

```text
见域
│
├─ 对话
├─ 角色
├─ 资料
└─ 我的
```

## 3. 页面结构初稿

### 3.1 对话

定位：见域 Top 1 核心页面，用户与一个或多个 Skill 角色持续交流的主要空间。

```text
对话
├─ 当前会话
├─ 参与 Skill 角色
├─ @角色
├─ 增加 Skill 角色
├─ 交叉讨论
└─ 会话记录（左上角进入）
```

初步层级判断：

- 【会话记录】属于【对话】内的历史入口，不单独占用底部一级导航；
- 【增加 Skill 角色】是当前会话内的动作，不等同于【角色】一级页面；
- 【交叉讨论】由用户显式触发，不作为独立一级页面；
- Skill 角色详情、输入工具和会话操作属于对话内的二级交互。

### 3.2 角色

定位：发现、了解和管理可用于对话的 Skill 角色。

底部导航暂用短名称【角色】，页面标题可暂用【Skill 角色】。

```text
角色
├─ 推荐
├─ 全部角色
├─ 收藏
├─ 最近使用
└─ Skill 角色详情
```

待继续确认：

- 【推荐】【全部角色】【收藏】【最近使用】采用 Tab、筛选项还是页面分区；
- 是否需要独立的角色分类入口；
- 从角色详情执行【开始新对话】和【增加到当前会话】时，如何区分两个动作；
- 收藏与最近使用是否值得成为页面一级分区。

### 3.3 资料

定位：管理用户可以带入对话的资料，以及用户明确确认保存的成果。

一级导航和页面标题均使用【资料】，不再增加【资料与成果】中间层。页面内部暂按【资料 / 成果】两个主要分区组织。

```text
资料
├─ 资料
│  ├─ 文件
│  ├─ 链接
│  ├─ 摘录 / 文本
│  └─ 来源信息
└─ 成果
   ├─ 判断与决策
   ├─ 行动方案
   ├─ 知识笔记
   └─ 文稿等已保存内容
```

对象边界：

- 【资料】是用户选择带入对话的输入和依据；
- 【成果】是用户明确确认保存的可复用输出；
- 普通 Skill 角色回复和自动草稿不会自动成为成果；
- 【个人背景】不放在【资料】中，归入【我的】；
- 资料、成果和个人背景继续保持不同对象语义。

待审查：

- 【资料 / 成果】采用 Tab、分区首页还是两个二级页面；
- 文件、链接、摘录和来源信息的新增、搜索与筛选方式；
- 成果分类是否固定，以及用户是否可以自定义类型；
- 从对话选择资料、保存成果和返回全局页面的衔接方式。

### 3.4 我的

定位：管理用户自身的长期背景、模型配置、数据控制和应用偏好。

```text
我的
├─ 个人背景
├─ 模型与 API Key
├─ 数据与隐私
│  ├─ 遥测与诊断
│  ├─ 数据导出与删除
│  └─ 备份与恢复
├─ 设置
│  ├─ 外观
│  ├─ 字号与无障碍
│  └─ 其他应用偏好
└─ 关于见域
```

内容边界：

- 【个人背景】是用户主动维护、可选择带入对话的长期事实、偏好和约束；
- 【模型与 API Key】承载模型选择和 BYOK Key 池管理；
- 【数据与隐私】统一承载遥测、诊断、数据导出、删除、备份与恢复；
- 【设置】只承载外观、字号、无障碍等应用偏好，不作为所有配置的笼统容器；
- 【关于见域】承载版本、开源许可和必要的 AI 模拟身份说明。

待审查：

- 个人背景在【我的】中的展示和编辑层级；
- 模型选择与 API Key 管理是否保留同一入口；
- 数据导出、删除、备份和恢复的风险分级与确认关系；
- 设置中的实际应用偏好范围；
- 关于见域需要承载的法务、许可和身份说明。

## 4. 当前层级判断

| 内容 | 当前暂定层级 | 说明 |
|---|---|---|
| 对话 | 一级页面 | Top 1 核心页面 |
| 角色 | 一级页面 | Skill 角色发现与管理入口 |
| 资料 | 一级页面 | 内部分为资料与成果，二者保持对象语义区分 |
| 我的 | 一级页面 | 用户背景、模型配置、数据控制和应用偏好入口 |
| 会话记录 | 对话内入口 | 当前从左上角进入 |
| Skill 角色详情 | 二级页面或浮层 | 不占用一级导航 |
| 增加 Skill 角色 | 对话内动作 | 不等于角色库页面 |
| 交叉讨论 | 对话内显式动作 | 结束后回到普通对话 |
| 资料详情 | 二级页面 | 具体形态待设计 |
| 成果详情 | 二级页面 | 具体形态待设计 |
| 个人背景 | 【我的】下的二级能力 | 用户主动维护并选择带入对话 |
| 模型与 API Key | 【我的】下的二级管理页面 | 管理模型选择与 BYOK Key 池 |
| 数据与隐私 | 【我的】下的二级管理能力 | 包含遥测、导出、删除、备份与恢复 |
| 设置 | 【我的】下的二级管理能力 | 只承载应用偏好 |
| 关于见域 | 【我的】下的二级页面 | 版本、许可和必要身份说明 |
