# 【我的】主页面候选 C｜卡片总览

> 图片类型：完整一级页面候选图
>
> 输出：1 张 1440 × 3200 Android 竖屏图片
>
> 目的：验证以数据控制和状态总览为核心的卡片式【我的】页面。

## 1. 必须继承

遵循[共享视觉基线](../共享/jianyu-shared-visual-baseline.md)。底部导航完整显示“对话 / 角色 / 资料 / 我的”，当前【我的】蓝色选中。

## 2. 顶部栏

- 标题：`我的`
- 副标题：`你的信息，由你决定如何使用`
- 右侧无账号入口。

## 3. 数据控制主卡

首屏第一张横向大卡：

- 图标：浅蓝紫盾牌 / 本地设备；
- 标题：`数据与隐私`
- 说明：`查看本地数据、导出、删除和诊断设置`
- 三个弱状态：`遥测关闭`、`0 个云端交互授权`、`尚未备份`
- 按钮：`管理数据`

状态必须使用文字，不只靠颜色；不写“完全安全”。

## 4. 三张功能卡

纵向错落但对齐的白色大圆角卡：

### 个人背景

- 浅薰衣草图标；
- `已保存 4 项`
- 摘要：`目标、时间、基础、表达偏好`
- 入口：`管理背景`

### 模型与 API Key

- 浅蓝图标；
- `Gemini`
- `2 个可用 Key`
- 入口：`管理模型`

### 应用设置

- 浅薄荷或中性灰图标；
- `跟随系统外观`
- `默认字号`
- 入口：`打开设置`

## 5. 页尾

两行弱列表：

- `备份与恢复`
- `关于见域`

底部显示版本号。

## 6. 视觉重点

- 比方案 B 更强调用户控制而非个人背景；
- 卡片状态简短，不做图表和百分比；
- 主卡不使用高饱和安全绿；
- 页面仍柔和、友好，不像隐私合规后台。

## 7. 用户主要比较点

- 数据控制是否适合作为第一视觉；
- 页面是否过于严肃；
- 状态信息是否有价值；
- 与对话页轻柔人物化风格是否协调。
