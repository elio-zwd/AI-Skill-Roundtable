# 【我的】页面组件与状态板候选

> 图片类型：组件与状态样式板
>
> 输出：1 张 1440 × 3200 浅色 Android UI 设计板

## 1. 画板结构

- 标题：`我的页面组件与状态`
- 冷紫灰背景；
- 分组展示；
- 遵循[共享视觉基线](../共享/jianyu-shared-visual-baseline.md)。

## 2. 组件

### 设置与入口

- 普通设置行；
- 带副标题设置行；
- 带右侧值与 Chevron；
- 带开关；
- 带状态 Chip；
- 危险操作行。

### 卡片

- 个人背景 Hero；
- 数据与隐私状态卡；
- 模型与 Key 状态卡；
- 备份状态卡；
- 关于见域信息卡。

### 控件

- 开关开 / 关；
- 单选行；
- 多选勾选；
- 脱敏 Key 行；
- 紫色描边新增按钮；
- 蓝色主要按钮；
- 红色危险文字按钮。

## 3. 状态

在画板下半部分展示：

1. 个人背景为空：`还没有个人背景`
2. API Key 为空：`还没有导入 API Key`
3. 备份为空：`尚未创建备份`
4. 数据读取失败：`暂时无法读取数据概览`
5. 操作成功 Snackbar：`个人背景已保存`

## 4. 要求

- 不出现账号头像、会员等级；
- 不显示完整 Key；
- 状态文案不作绝对安全承诺；
- 危险操作使用文字和图标共同提示；
- 所有中文可读，无伪文字；
- 不画 Figma 标尺和开发红线。
