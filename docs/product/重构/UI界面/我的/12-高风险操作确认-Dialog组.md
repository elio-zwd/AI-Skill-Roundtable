# 【我的】高风险操作确认 Dialog 组候选

> 图片类型：三张确认 Dialog 展开态
>
> 输出：3 张独立 1440 × 3200 Android 竖屏图片
>
> 背景统一使用对应二级页面并覆盖 35%～45% Scrim。

## 1. 共享视觉

遵循[共享视觉基线](../共享/jianyu-shared-visual-baseline.md)。

- 居中白色大圆角 Dialog；
- 图标、标题、影响说明、确认方式、取消与危险按钮；
- 危险按钮使用红色文字或克制红色描边；
- 默认焦点放在取消 / 返回，不放在危险操作；
- 不使用系统浏览器式 Alert 样式。

## 2. Dialog A｜删除所有本地数据

- 背景：数据与隐私页；
- 红色线性删除图标；
- 标题：`删除所有本地数据？`
- 影响：`将删除当前 App 中的会话、资料、成果、个人背景和设置。此操作不会自动删除旧 App。`
- 确认输入：`请输入“删除”以继续`
- 按钮：`取消` / `确认删除`
- 不写“无法恢复”，除非当前实现确实无可用备份恢复路径；可写 `请先确认是否已经保留需要的备份。`

## 3. Dialog B｜从备份恢复

- 背景：备份与恢复页；
- 琥珀色恢复图标；
- 标题：`恢复这个备份？`
- 展示备份时间、版本、内容范围；
- 影响：`恢复可能替换当前 App 中的部分数据。继续前请核对范围。`
- 按钮：`取消` / `查看影响并继续`
- 该按钮不是直接恢复，下一步仍需展示影响明细。

## 4. Dialog C｜移除 API Key

- 背景：模型与 API Key 页；
- 红色钥匙 / 删除图标；
- 标题：`移除这个 API Key？`
- 仅显示脱敏尾号：`········7K2Q`
- 说明：`移除后需要重新导入才能使用。其他 Key 不受影响。`
- 按钮：`取消` / `移除 Key`

## 5. 不要生成

- 完整 Key；
- 默认选中危险按钮；
- 一次确认同时执行多个无关操作；
- 旧 App 自动卸载 / 清空；
- “100% 可恢复”或“永不丢失”。
