# 遥测与诊断页候选

> 图片类型：完整二级页面
>
> 输出：1 张 1440 × 3200 Android 竖屏图片

## 1. 页面目标

让用户理解、配置和清空诊断数据，不把完整 Prompt、附件和模型回复当作默认遥测正文展示。

## 2. 顶部栏

- 左侧返回箭头；
- 标题：`遥测与诊断`
- 右侧帮助图标。

## 3. 总开关

遵循[共享视觉基线](../共享/jianyu-shared-visual-baseline.md)。

浅蓝紫大卡：

- 标题：`诊断数据`
- 说明：`用于帮助定位崩溃、请求失败和性能问题`
- 右侧开关：关闭
- 状态：`当前未启用`

## 4. 数据范围

分组标题：`启用后可记录`

- 崩溃与错误类型；
- 请求耗时与成功 / 失败状态；
- 设备与 App 版本；
- 不默认保存完整消息正文、完整附件和完整 API Key。

每项左侧 Check / 禁止图标，区分记录与不记录。

## 5. 云端交互授权

白色圆角卡：

- 标题：`云端交互授权`
- 说明：`查看哪些功能会把你选择的内容发送给模型服务`
- 右侧：`查看详情`。

## 6. 记录管理

- `查看诊断摘要`
- `导出诊断记录`
- `清空诊断记录`，红色文字但无红底。

底部弱说明：

`关闭遥测不会删除已有记录；你可以单独清空。`

## 7. 不要生成

- 完整用户 Prompt 示例；
- 完整附件内容；
- 完整模型回复；
- 完整 API Key；
- HTTP 堆栈铺满页面；
- 默认已开启且无法关闭。
