# 数据与隐私页候选

> 图片类型：完整二级页面
>
> 输出：1 张 1440 × 3200 Android 竖屏图片

## 1. 顶部栏

- 左侧返回箭头；
- 标题：`数据与隐私`
- 无额外顶部动作；
- 二级页面不显示底部一级导航。

## 2. 顶部说明

遵循[共享视觉基线](../共享/jianyu-shared-visual-baseline.md)。

浅蓝紫信息卡：

- 标题：`你的数据控制`
- 说明：`查看本地数据、云端交互授权、导出与删除选项。`
- 不承诺全部数据永远只在本地。

## 3. 分组内容

### 数据概览

三行状态：

- `会话数据`：`保存在当前 App 中`
- `资料与成果`：`8 项`
- `个人背景`：`4 项`

这些是候选图示例，不表示当前实现统计已经完成。

### 隐私控制

- `云端交互授权`：右侧 `查看`
- `敏感资料使用确认`：开关开启
- `遥测与诊断`：右侧 `已关闭`

### 数据操作

- `导出我的数据`
- `备份与恢复`
- `清空遥测记录`

### 危险区域

白底淡红描边卡，仅一项：

- `删除所有本地数据`
- 红色文字，说明 `将删除当前 App 中的会话、资料、成果、个人背景和设置`
- 点击后必须进入确认 Dialog。

## 4. 旧 App 边界提示

页面底部弱灰提示：

`旧包 com.elio.skillroundtable 的数据不会自动迁移到见域，也不会由本页面自动清除。`

## 5. 不要生成

- “零风险”“绝对隐私”；
- 自动删除旧 App；
- 直接在列表点击后立即清空；
- 显示用户消息正文作为遥测示例；
- 云端账户同步开关，除非后续产品明确实现。
