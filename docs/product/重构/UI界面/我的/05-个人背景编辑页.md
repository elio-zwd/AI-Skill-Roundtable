# 个人背景编辑页候选

> 图片类型：完整编辑二级页面
>
> 输出：1 张 1440 × 3200 Android 竖屏图片

## 1. 当前状态

用户正在编辑“可用时间”。

## 2. 顶部栏

- 左侧关闭 / 返回；
- 标题：`编辑个人背景`
- 右侧文字按钮：`保存`
- 页面不显示底部一级导航。

## 3. 表单

遵循[共享视觉基线](../共享/jianyu-shared-visual-baseline.md)。

### 类型

下拉选择：`时间与约束`

### 标题

输入框：`可用时间`

### 内容

多行输入框：

`工作日每天 1.5 小时，周末每天 4 小时。晚上 22:30 后不安排高强度学习。`

右下显示字符计数，但不强调硬性上限。

### 使用提示

勾选项：

- `在对话选择个人背景时显示这一项`（已勾选）
- `将此项标记为敏感内容`（未勾选）

弱说明：`保存不会自动把内容发送给任何 Skill 角色。`

## 4. 底部操作

- 主按钮：`保存修改`
- 次按钮：`取消`
- 页面最底部红色文字：`删除这项个人背景`

删除需要后续确认 Dialog，本图不直接删除。

## 5. 不要生成

- 自动从聊天提取并勾选保存；
- 无法关闭的长期记忆；
- 保存即全局共享；
- 生硬的数据库字段表单；
- 完整敏感信息示例。
