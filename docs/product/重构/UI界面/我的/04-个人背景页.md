# 个人背景页候选

> 图片类型：完整二级页面
>
> 输出：1 张 1440 × 3200 Android 竖屏图片

## 1. 页面目标

让用户查看、编辑、停用和选择可复用的长期背景。个人背景由用户主动保存，不是系统自动画像。

## 2. 顶部栏

遵循[共享视觉基线](../共享/jianyu-shared-visual-baseline.md)。

- 左侧返回箭头；
- 标题：`个人背景`
- 右侧紫色 `+`；
- 二级页面不显示底部一级导航。

## 3. 顶部说明卡

极浅薰衣草信息卡：

- 标题：`由你决定何时使用`
- 说明：`个人背景只有在你选择后才会带入会话，可以随时编辑或停用。`
- 左侧线性盾牌 / 人物图标。

## 4. 分类与列表

横向筛选 Chip：

- `全部 4`（蓝色选中）
- `目标`
- `时间与约束`
- `经验与能力`
- `偏好`

列表显示四张白色卡：

1. `职业目标`
   - `3 个月内转向嵌入式岗位`
2. `可用时间`
   - `工作日每天 1.5 小时，周末每天 4 小时`
3. `当前基础`
   - `有 C 语言基础，STM32 项目经验较少`
4. `表达偏好`
   - `优先给出结构化步骤和明确下一步`

每张卡包含：

- 类型弱标签；
- 标题与两行内容；
- 最近更新时间；
- 状态 `可选择使用`；
- 右侧三点菜单。

不在列表中显示“默认发送给全部角色”。

## 5. 底部新增入口

紫色胶囊 FAB：`+ 添加个人背景`

## 6. 不要生成

- 系统推断标签；
- “我们已经了解你”；
- 健康、财务等敏感字段模板自动展开；
- 默认全局启用；
- 账号资料、头像和手机号。
