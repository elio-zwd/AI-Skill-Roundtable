# 对话选择个人背景 Bottom Sheet 候选

> 图片类型：与对话 Composer 联动的选择 Bottom Sheet
>
> 输出：1 张 1440 × 3200 Android 竖屏图片

## 1. 触发背景

用户在【对话】页的资料 / 上下文入口中选择“个人背景”。背景保留对话与输入区，使用轻 Scrim。

## 2. Sheet

遵循[共享视觉基线](../共享/jianyu-shared-visual-baseline.md)。

- 标题：`选择个人背景`
- 副说明：`只把你确认的背景用于当前会话`
- 搜索框：`搜索个人背景`
- 高度约屏幕 62%，内部滚动。

## 3. 背景条目

显示四项固定个人背景：

- 职业目标（已选）
- 可用时间（已选）
- 当前基础（未选）
- 表达偏好（已选）

每行包含类型、标题、两行内容预览和复选框。选中行使用极浅蓝背景与蓝色 Check。

若某项被用户标记敏感，行内显示琥珀色弱标签 `敏感`，默认不选。本示例可给“当前基础”显示该标签。

## 4. 底部确认

- 左侧：`已选择 3 项`
- 右侧蓝色按钮：`用于当前会话`
- 弱说明：`本次选择不会改变其他会话，也不会自动发送给所有角色。`

## 5. 不要生成

- 自动全选；
- 系统推断出来的隐藏背景；
- “永久记住我”；
- 账号身份资料；
- 未确认即发送。
