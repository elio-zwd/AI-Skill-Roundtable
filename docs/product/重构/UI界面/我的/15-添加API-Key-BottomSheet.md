# 添加 API Key Bottom Sheet 候选

> 图片类型：模型与 API Key 页上的安全输入 Bottom Sheet
>
> 输出：1 张 1440 × 3200 Android 竖屏图片

## 1. Sheet

遵循[共享视觉基线](../共享/jianyu-shared-visual-baseline.md)。背景 35% Scrim。

- 标题：`添加 API Key`
- 副说明：`Key 由你自行导入，保存后只显示脱敏信息`
- 右上关闭；
- 键盘弹出，Sheet 使用 IME Insets，不被遮挡。

## 2. 表单

1. `服务`
   - 下拉：`Gemini`
2. `名称`
   - `我的 Gemini Key`
3. `API Key`
   - 密码输入框，只显示圆点；
   - 右侧眼睛图标允许短暂查看，但图片默认保持隐藏；
4. 勾选：`我确认这是自己有权使用的 Key`

## 3. 操作

- 次按钮：`取消`
- 主按钮：`验证并保存`
- 按钮下弱说明：`验证需要向对应模型服务发起最小请求。`

## 4. 不要生成

- 任何完整 Key 示例；
- 根目录 `.env`；
- 内置 Key；
- 复制、分享完整 Key 的按钮；
- “保证可用”；
- 绕过配额或限流文案。
