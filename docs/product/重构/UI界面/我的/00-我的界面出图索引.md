> 一级名称：【我的】。

## 1. 页面定位

【我的】不是账号社交主页，也不是把所有功能塞在一起的杂项页面。它负责：

- 用户主动维护的个人背景；
- 模型与 BYOK API Key；
- 数据、隐私、遥测、导出、删除、备份与恢复；
- 外观、字号、无障碍等应用偏好；
- 关于见域、版本、许可与 AI 模拟身份说明。

个人背景可以在对话中被用户选择使用，但不会自动成为所有角色都能看到的长期画像。

## 4. 固定示例内容

个人背景：

- 职业目标：`3 个月内转向嵌入式岗位`
- 可用时间：`工作日每天 1.5 小时，周末每天 4 小时`
- 当前基础：`有 C 语言基础，STM32 项目经验较少`
- 表达偏好：`优先给出结构化步骤和明确下一步`

模型与 Key：

- 当前文本模型：`Gemini`
- Key 数量：`2 个可用 Key`
- Key 只显示脱敏尾号，不展示完整值。

候选图片展示的能力不等于当前代码已经全部实现；最终描述和开发必须再次核对工程事实。
