# 【我的】主页面候选 A｜分组设置列表

> 图片类型：完整一级页面候选图
>
> 输出：1 张 1440 × 3200 Android 竖屏图片
>
> 目的：验证最简单、最熟悉的分组列表是否足以承载【我的】。

## 1. 必须继承

遵循[共享视觉基线](../共享/jianyu-shared-visual-baseline.md)。底部导航为“对话 / 角色 / 资料 / 我的”，【我的】蓝色选中。

## 2. 顶部区域

- 标题：`我的`
- 副标题：`管理你的背景、模型和数据`
- 不显示账号头像、昵称、会员等级或登录按钮；
- 右侧不放复杂操作。

## 3. 页面布局

### 个人

白色分组卡第一行：

- 图标：浅薰衣草人物 / 文档；
- 标题：`个人背景`
- 说明：`已保存 4 项，可在对话中选择使用`
- 右侧 Chevron。

### AI 与模型

第二组：

- `模型与 API Key`
- 说明：`Gemini · 2 个可用 Key`
- 左侧浅蓝紫模型图标；
- 右侧 Chevron；
- 不显示完整 Key。

### 数据

同一白色分组卡内三行：

1. `数据与隐私`：`管理导出、删除和数据权限`
2. `备份与恢复`：`本地备份与恢复`
3. `遥测与诊断`：`诊断数据已关闭`

行间使用极淡分割线；关闭状态使用灰蓝文字，不用红色警告。

### 应用

两行：

1. `设置`：`外观、字号与无障碍`
2. `关于见域`：`版本、许可与角色说明`

页面底部弱灰版本：`见域 1.0`

## 4. 视觉重点

- 所有设置项是宽松的圆角列表行，不使用老式密集系统设置样式；
- 左侧图标放在低饱和圆角方块中；
- 分组标题使用次级灰蓝小字；
- 不用大面积彩色 Hero；
- 不把“我的”变成账号中心。

## 5. 不要生成

- 登录、手机号、头像上传、VIP；
- 云同步已开启等未经确认事实；
- 完整 API Key；
- “绝对安全”“永不丢失”；
- 系统日志、Run ID。

## 6. 用户主要比较点

- 是否过于像普通设置页；
- 个人背景是否足够突出；
- 信息是否清楚而不拥挤；
- 数据与设置分组是否符合直觉。
