# 备份与恢复页候选

> 图片类型：完整二级页面
>
> 输出：1 张 1440 × 3200 Android 竖屏图片
>
> 页面描述为候选目标，不代表备份能力已经实现。

## 1. 顶部栏

- 左侧返回箭头；
- 标题：`备份与恢复`
- 右侧帮助图标。

## 2. 当前状态卡

遵循[共享视觉基线](../共享/jianyu-shared-visual-baseline.md)。

浅薰衣草大卡：

- 图标：本地文件夹 + 盾牌；
- 标题：`尚未创建备份`
- 说明：`创建本地备份文件，用于在见域中恢复数据。`
- 主按钮：`创建备份`

不显示云端同步或自动备份已经开启。

## 3. 备份内容

白色分组卡显示可包含：

- 会话；
- 资料与成果；
- 个人背景；
- 设置；
- API Key 单独标注：`不会导出完整 Key`。

## 4. 恢复

标题：`从备份恢复`

大号紫色描边按钮：`选择备份文件`

说明卡：

- `恢复前会先展示备份时间、内容范围和影响。`
- `恢复不会迁移旧包 com.elio.skillroundtable 的数据。`

## 5. 历史备份

候选图显示一条示例：

- `见域备份 · 2026-08-30 21:15`
- 大小：`18.4 MB`
- 状态：`本地文件`
- 右侧三点菜单。

该示例用于视觉，不表示系统已实际创建备份。

## 6. 不要生成

- “自动云备份已开启”；
- 备份完整 API Key；
- 一键恢复且不显示影响；
- 恢复成功保证；
- 旧 App 数据自动迁移；
- iCloud、Google Drive 等未经选择的第三方品牌。
