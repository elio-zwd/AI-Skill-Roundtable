# 设置页候选

> 图片类型：完整二级页面
>
> 输出：1 张 1440 × 3200 Android 竖屏图片

## 1. 页面边界

【设置】只承载应用偏好，不重复模型、API Key、数据与隐私、备份和个人背景。

## 2. 顶部栏

- 左侧返回箭头；
- 标题：`设置`
- 无右侧动作；
- 二级页面不显示底部一级导航。

## 3. 分组

遵循[共享视觉基线](../共享/jianyu-shared-visual-baseline.md)。

### 外观

- `主题`：`跟随系统`
- `角色弱色彩`：开关开启
- `减少透明效果`：开关关闭

### 文字与显示

- `字号`：`默认`
- `内容密度`：`舒适`
- `Markdown 排版`：`标准`

### 无障碍

- `减少动效`：开关关闭
- `增强文字对比度`：开关关闭
- `图标同时显示文字说明`：开关开启

### 对话偏好

- `发送前确认敏感资料`：开关开启
- `默认显示消息时间`：开关开启

每项使用宽松白色圆角分组列表和淡分割线。

## 4. 视觉重点

- Android 设置习惯，但沿用见域大圆角、宽松留白；
- 开关使用蓝色选中；
- 右侧值使用灰蓝文字与 Chevron；
- 不把未实现选项写成“已生效”保证，候选图只表达目标结构。

## 5. 不要生成

- 模型和 Key；
- 数据删除和备份；
- iOS 专属动态与触觉选项；
- 过密系统工程选项；
- 开发者模式、Run 参数。
