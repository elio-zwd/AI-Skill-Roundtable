# 数据导出范围 Bottom Sheet 候选

> 图片类型：数据与隐私页上的 Modal Bottom Sheet
>
> 输出：1 张 1440 × 3200 Android 竖屏图片

## 1. Sheet

遵循[共享视觉基线](../共享/jianyu-shared-visual-baseline.md)。背景为数据与隐私页，35% Scrim。

- 标题：`导出我的数据`
- 副说明：`选择要包含的内容`
- 右上关闭。

## 2. 可选范围

复选列表：

- `会话与消息`（已选）
- `资料与成果`（已选）
- `个人背景`（已选）
- `应用设置`（已选）
- `遥测与诊断摘要`（未选）

每项有数量或范围说明，不显示正文预览。

固定不可选说明行：

- 锁形图标；
- `完整 API Key 不会包含在导出文件中`

## 3. 文件格式

单选：

- `结构化备份文件`（选中）
- `可阅读的数据副本`

最终支持格式需要工程核对，本图只表达选择层级。

## 4. 底部操作

- `取消`
- 蓝色 `继续`
- 弱说明：`下一步会展示导出位置和影响范围。`

## 5. 不要生成

- 完整 Key 导出开关；
- 默认上传云端；
- “导出后永久安全”；
- 未确认就开始写文件。
