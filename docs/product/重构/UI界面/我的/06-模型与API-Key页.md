# 模型与 API Key 页候选

> 图片类型：完整二级管理页面
>
> 输出：1 张 1440 × 3200 Android 竖屏图片
>
> 注意：图片只展示脱敏示例，不得生成或回显真实 Key。

## 1. 顶部栏

- 左侧返回箭头；
- 标题：`模型与 API Key`
- 右侧帮助图标；
- 二级页面不显示底部一级导航。

## 2. 当前模型

遵循[共享视觉基线](../共享/jianyu-shared-visual-baseline.md)。

分组标题：`文本模型`

白色大圆角卡：

- 标题：`Gemini`
- 状态 Chip：`当前使用`
- 说明：`用于文字对话、联网搜索和资料理解`
- 右侧 Chevron：`选择模型`

如果候选图展示第二个供应商，只能作为未选项，不写成已配置事实。

## 3. API Key 池

标题：`API Key`

顶部弱说明：

`Key 由你自行导入，并在界面中始终脱敏显示。`

显示两张 Key 卡：

1. `Key 1  ········7K2Q`
   - 绿色弱状态：`可用`
   - 最近使用：今天 10:27
2. `Key 2  ········9M4A`
   - 灰蓝状态：`备用`
   - 最近使用：昨天

每张卡右侧三点菜单；不显示复制完整 Key。

紫色描边按钮：`+ 添加 API Key`

## 4. 安全说明卡

极浅蓝紫卡：

- `不会在页面或诊断日志中完整显示 Key。`
- `移除 Key 后，需要重新导入才能再次使用。`

措辞不能写“绝对不会泄露”“百分之百安全”。

## 5. 底部设置

列表行：

- `Key 使用顺序`
- `请求失败处理`

右侧只显示概括值，不展示工程参数。

## 6. 不要生成

- 真实 Gemini Key 格式完整字符串；
- 根目录 `.env`；
- 内置备用生产 Key；
- 一键绕过限流；
- 调用次数排行榜；
- Run ID、HTTP 日志。
