# 给后续 AI 的接手提示词

使用前把尖括号占位替换为本批真实路径。各 AI 均读取 `D:/My_Elio/AI-Skill-Roundtable/docs/product/重构/UI界面/UI-RECONSTRUCTION-HANDOFF.md`，不要依赖其他对话记忆。

## 1. 首次试点：规格 AI

```text
请在 D:/My_Elio/AI-Skill-Roundtable 中为“我的”主页面 B 整理可实施 UI 规格，先不写生产代码。

先读取根 AGENTS.md、当前产品定义、UI-RECONSTRUCTION-HANDOFF.md、共享视觉基线与对话页规格。
用户已认可的图片是：
docs/product/重构/UI界面/我的/参考图片/02-我的主页面-B-个人控制台-选定.png
对应原描述是：
docs/product/重构/UI界面/我的/02-我的主页面-B-个人控制台.md
用户明确要求：有一个与对话页一致的用户头像，且可以切换。

本次授权你读取并分析上述选定图和对话视觉参考。不要把“浏览器出图”中的其他候选自动视为已选定。
使用“实施交接/单页实施规格模板.md”，在“实施规格/UI-01/”生成选图记录和“我的主页面-B-实施规格.md”。
图中可见事实、尺寸估计、补充交互建议分别标注。复用已有共享风格，写清精确文案、资源、状态、跳转、返回、头像切换和保存行为。
只读检查相关现有 UI、状态、数据入口和依赖，列出已有能力与缺口；图中入口不代表底层功能已存在。
有影响业务范围的未决事项列出推荐方案供用户审查；继续完成其余明确内容。不要把草稿标为已审查。
完成后给出文档路径和最少必要的待决定项。
```

其他批次沿用该提示词，替换页面、已选图片和对应候选描述；没有用户选图记录时先整理候选与待选项，不自行决定互斥方案。

## 2. 开发 AI

```text
请实施见域 UI 重构批次 <UI-xx>。
工程：D:/My_Elio/AI-Skill-Roundtable。
输入：<选图记录路径>、<已审查规格路径>以及记录中的原始选定图片。

先读取 AGENTS.md、目标目录规则和 UI-RECONSTRUCTION-HANDOFF.md，核查最新基线、开放 PR、现有依赖与调用链。
同时看图和读规格；图负责视觉，规格负责交互和准确文案，产品规范负责业务边界。
列出修改范围、既有能力、缺口、验证方案，再按本批范围实施。使用独立分支，保持现有对话能力可用。
遵守 Compose 的 Route/Screen/Components 分层，复用现有主题和资产。所有生产操作接真实状态，不用假数据或空回调宣称完成。
涉及未授权底层能力时明确列为依赖，继续可独立完成部分。
执行要求的编译、单元测试及适用的 UI 检查；在设备或模拟器运行，按指定样例数据和状态截图。
把运行截图、环境、差异与修复记录放到“实施验收/<UI-xx>/”。逐项对比选定图并优化，复验相关交互与对话回归。
报告真实结果、剩余差异、未完成项与人工验收步骤；无运行截图就标明视觉验收未完成。
未经授权不要合并 PR、关闭 PR 或删除分支。
```

## 3. 独立验收 AI（只读）

```text
请只读验收见域 UI 批次 <UI-xx>，不要修改代码或参考图。
输入：<选图记录>、<已审查规格>、<开发交付报告>、<运行截图及环境目录>。
读取根和 UI 目录规则、当前产品规范、UI-RECONSTRUCTION-HANDOFF.md。

核对截图确实来自本次实现，环境、数据、页面状态及代码版本可追溯。
逐页对比参考图与运行截图：布局层级、固定/滚动区域、字体、间距、卡片、头像、图标、颜色、Sheet/Dialog、系统安全区。
将系统时间等无关差异排除，不能通过不等比缩放隐藏 UI 差异，也不要凭整体相似度分数判定通过。
检查关键交互的代码和测试证据，条件允许时运行验证；静态检查与实际运行结果分开报告。
输出差异清单，每项包括区域、期望、实际、严重程度、建议和证据路径。
检查现有对话能力、四项导航返回链、角色平级、资料与成果区分、个人背景显式选择、Key 脱敏是否保持。
缺截图、缺测试或核心交互未实现要明确指出；只读验收不替用户接受未决设计。
给出可交给开发 AI 的修复清单及复验范围。
```
