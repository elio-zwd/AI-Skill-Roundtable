# 【角色】界面出图索引

> 状态：候选方案，待用户看图选择
>
> 页面一级名称：【角色】；主页面标题：【Skill 角色】。

## 1. 页面目标

帮助用户发现、理解和管理可以参与对话的 Skill 角色，并清楚区分：

- 浏览一个角色；
- 收藏一个角色；
- 开始一段新对话；
- 将角色增加到当前会话。

页面不能表现成插件市场、Agent 编排后台或角色排行榜。

## 2. 主页面候选

| 方案 | 核心组织方式 | 主要比较点 |
|---|---|---|
| [A｜推荐优先](./01-角色主页面-A-推荐优先.md) | 推荐 Hero + 最近使用 + 全部角色 | 新用户是否更容易开始 |
| [B｜分类目录](./02-角色主页面-B-分类目录.md) | 分类 Chip + 双列目录 | 查找效率与信息密度 |
| [C｜个人角色架](./03-角色主页面-C-个人角色架.md) | 收藏与最近优先 | 老用户的持续使用效率 |

三张图必须保持同一角色数据和视觉基线，便于只比较信息架构。

## 4. 固定示例角色

所有图片优先复用：

- 规划教练：拆解目标与行动步骤；
- 系统思考者：识别结构、依赖与风险；
- 研究员：信息检索、证据评估与事实核查；
- 产品顾问：用户价值、需求分析与产品策略；
- 苏格拉底：通过提问检查假设，真实人物型 AI 模拟角色；
- 史蒂夫·乔布斯：聚焦重点、取舍与表达，真实人物型 AI 模拟角色。

同一角色在所有图中必须保持相同脸部、服装、姓名与弱识别色。
