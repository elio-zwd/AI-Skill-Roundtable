背景为角色搜索与筛选页，使用 35% Scrim。遵循[共享视觉基线](../共享/jianyu-shared-visual-baseline.md)。

## 4. 视觉与边界

- 选中项使用蓝色 Check 和浅蓝底；
- “AI 模拟角色”是身份类型，不是风险红色标签；
- 不显示模型、Prompt、temperature 和 Agent 参数；
- Sheet 可滚动，底部操作固定。
