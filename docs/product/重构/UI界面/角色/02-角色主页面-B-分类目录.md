# 【角色】主页面候选 B｜分类目录

> 图片类型：完整一级页面候选图
>
> 输出：1 张 1440 × 3200 Android 竖屏图片
>
> 目的：判断“搜索和分类优先”是否比大推荐卡更高效。

## 1. 必须继承

遵循[共享视觉基线](../共享/jianyu-shared-visual-baseline.md)。底部导航为“对话 / 角色 / 资料 / 我的”，【角色】蓝色选中。

## 2. 页面状态

当前选中分类：`思考方法`。角色数据与其他候选图保持一致。

## 3. 页面布局

### 顶部栏

- 标题：`Skill 角色`
- 右侧：收藏图标、更多图标
- 标题下为全宽搜索框：`搜索角色、能力或问题`

### 分类区

横向可滚动圆角 Chip：

- `全部`
- `思考方法`（蓝色选中）
- `职业成长`
- `研究学习`
- `产品创造`
- `沟通表达`

Chip 下方一行弱提示：`按角色最稳定的思考方式分类`

### 分类说明卡

一张矮横卡：

- 标题：`思考方法`
- 说明：`适合检查假设、梳理结构和发现盲区`
- 右侧使用极淡线性节点图装饰，不使用人物 Hero。

### 双列角色目录

两列等宽卡片，每张卡约 1.2:1 高宽比：

- 上半部分为人物半身头像，背景使用角色弱色；
- 下半部分显示姓名；
- 一行定位；
- 最多两个小标签；
- 右上角收藏星标；
- 整卡可点击，不显示“增加”按钮。

首屏至少出现：

- 系统思考者；
- 苏格拉底；
- 规划教练；
- 研究员；
- 产品顾问；
- 史蒂夫·乔布斯。

真实人物型卡片姓名下方显示小号 `AI 模拟角色`。

## 4. 视觉重点

- 比方案 A 更规整、更像角色目录，但不能像电商商品网格；
- 卡片背景在浅薰衣草、浅薄荷、浅蓝之间轻微变化；
- 所有卡片权重平级，不以卡片大小表达角色等级；
- 分类 Chip 选中态蓝色，收藏使用紫色；
- 双列布局在 412dp 逻辑宽度下仍保留清楚文字。

## 5. 不要生成

- 排行榜、热度数字、评分；
- 三列或四列过密网格；
- 每张卡塞入长段角色简介；
- 角色卡上的“主/副”“正/反”；
- 彩色 Emoji 分类图标。

## 6. 用户主要比较点

- 双列卡片是否比单列更容易扫视；
- 分类是否帮助用户理解，而不是增加选择负担；
- 人物图占比是否合适；
- 长中文角色名和说明是否容易截断。
