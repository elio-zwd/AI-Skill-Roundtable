# 【角色】页面组件板候选

> 图片类型：组件样式板
>
> 输出：1 张 1440 × 3200 的浅色 Android UI 组件板
>
> 目的：单独比较角色相关组件，而不是比较页面布局。

## 1. 组件板背景

- 极浅冷紫灰；
- 顶部标题：`Skill 角色组件`
- 使用 2 列或分区画板布局；
- 每组有中文名称，但不要画开发尺寸标注线。

## 2. 必须展示的组件

### 人物身份

1. 圆形消息 / 列表头像；
2. 半身 cutout 大头像；
3. 真实人物型角色的 `AI 模拟角色` 弱标签；
4. 收藏星标：未收藏 / 已收藏；
5. 最近使用弱文字。

### 卡片

1. 推荐 Hero 卡；
2. 双列目录卡；
3. 单列搜索结果卡；
4. 最近使用卡；
5. 角色详情能力信息卡。

角色统一使用：规划教练、系统思考者、研究员、苏格拉底。

### 标签与按钮

1. 分类 Chip：默认 / 选中；
2. 能力标签；
3. `查看角色` 紫色描边按钮；
4. `开始新对话` 蓝紫渐变按钮；
5. `增加到当前会话` 描边按钮；
6. 禁用按钮。

### 搜索与筛选

1. 空搜索框；
2. 已输入搜索框；
3. 启用筛选的小圆点；
4. 可关闭筛选 Chip。

## 3. 视觉规则

遵循[共享视觉基线](../共享/jianyu-shared-visual-baseline.md)。人物脸部和角色色必须与对话页一致。所有组件都使用真实中文，不出现随机伪文字。

## 4. 不要展示

- Figma 标尺或开发红线；
- 模型 Logo；
- 角色评分、价格和下载量；
- 主副角色、正反方徽章；
- 高饱和角色阵营色。
