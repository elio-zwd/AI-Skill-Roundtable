# 角色收藏与最近使用页面组候选

> 图片类型：两个正常内容二级页面
>
> 输出：2 张 1440 × 3200 Android 竖屏图片

## 1. 共享视觉

遵循[共享视觉基线](../共享/jianyu-shared-visual-baseline.md)。二级页面左上返回，不显示底部一级导航。

## 2. 图片 A｜收藏的角色

- 标题：`收藏的角色`
- 顶部搜索框：`搜索收藏`
- 筛选 Chip：`全部`、`专业角色`、`思维方法`、`AI 模拟角色`
- 单列宽卡显示：研究员、系统思考者、苏格拉底；
- 每卡包含头像、姓名、定位、两个能力标签、紫色实心收藏星标和 Chevron；
- 苏格拉底显示弱灰 `AI 模拟角色`；
- 右上更多菜单可进入“管理收藏”，但主图不展开。

## 3. 图片 B｜最近使用

- 标题：`最近使用`
- 按 `今天 / 昨天 / 更早` 分组；
- 显示规划教练、系统思考者、产品顾问、研究员；
- 每行包含头像、姓名、最近使用场景、时间和 `开始对话` 轻按钮；
- 顶部弱操作：`清除记录`，点击后必须确认，主图不展开；
- 最近使用只表示使用历史，不表示角色更高级。

## 4. 不要生成

- 好友在线、未读红点；
- 角色使用次数排行榜；
- 主角色标识；
- 清除记录后自动删除收藏或会话。
