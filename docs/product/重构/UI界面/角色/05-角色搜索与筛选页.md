# 角色搜索与筛选页候选

> 图片类型：完整二级页面
>
> 输出：1 张 1440 × 3200 Android 竖屏图片

## 1. 页面状态

用户从【角色】页点击搜索，输入：`帮助我做职业规划`

当前筛选：

- 分类：职业成长、思考方法；
- 需要联网：不限；
- 类型：全部角色；
- 排序：最相关。

## 2. 页面布局

遵循[共享视觉基线](../共享/jianyu-shared-visual-baseline.md)。

### 顶部搜索栏

- 左侧返回箭头；
- 中间大圆角搜索输入框，显示当前查询；
- 输入框右侧清除按钮；
- 最右筛选图标，右上有蓝色小圆点提示已启用筛选。

### 已选筛选条件

横向可滚动可关闭 Chip：

- `职业成长 ×`
- `思考方法 ×`
- `最相关`

右侧文字按钮：`清除`

### 结果说明

左侧：`找到 4 个 Skill 角色`

右侧：`排序：最相关`

### 搜索结果

单列卡片，显示：规划教练、系统思考者、产品顾问、苏格拉底。

每张卡包含：

- 人物头像；
- 姓名；
- 一句话定位；
- 与查询匹配的两条理由；
- 最多 3 个能力标签；
- 收藏星标；
- 右侧 Chevron。

苏格拉底显示弱灰 `AI 模拟角色`。

## 3. 筛选 Bottom Sheet 的可见预告

图片底部不展开 Sheet，但筛选图标必须清楚。筛选内容将在开发时包含：

- 角色分类；
- 专业角色 / 思维方法 / 真实人物模拟；
- 是否需要联网；
- 是否已收藏；
- 最近使用。

不要出现“模型厂商”“temperature”“Agent 参数”。

## 4. 视觉重点

- 搜索结果应强调“为什么适合这个问题”，而不是热度；
- 卡片比双列目录更适合阅读匹配理由；
- 搜索输入保持 Android 风格，不绘制 iOS Cancel 按钮；
- 二级页面不显示底部一级导航。
