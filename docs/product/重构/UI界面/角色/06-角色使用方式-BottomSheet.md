# 角色使用方式 Bottom Sheet 候选

> 图片类型：带背景上下文的 Bottom Sheet 展开态
>
> 输出：1 张 1440 × 3200 Android 竖屏图片

## 1. 触发背景

背景为“系统思考者”详情全屏页，用户点击页面底部主要操作区。背景使用 35% 左右黑色 Scrim。

遵循[共享视觉基线](../共享/jianyu-shared-visual-baseline.md)。

## 2. Sheet 结构

- 白色；
- 顶部左右 24～28dp 大圆角；
- 顶部中央灰色 Handle；
- 标题：`使用系统思考者`
- 副说明：`选择这次要怎么开始`
- 右上关闭按钮。

## 3. 三个选项

### 开始新对话

- 蓝色圆角图标容器，聊天气泡 + 图标；
- 标题：`开始新对话`
- 说明：`创建一段独立会话，由系统思考者参与`
- 右侧 Chevron；
- 整行浅蓝选中感，但尚未点击。

### 增加到当前会话

- 紫色人物 + 图标；
- 标题：`增加到当前会话`
- 说明：`加入“如何把复杂目标拆成可执行计划？”`
- 右侧 Chevron；
- 不显示“主角色”“副角色”。

### 收藏角色

- 线性星标图标；
- 标题：`收藏角色`
- 说明：`稍后可以在角色页快速找到`
- 当前未收藏，右侧为空心星标。

## 4. 底部提示

弱灰小字：

`增加角色不会改变其他角色的地位，也不会自动发起交叉讨论。`

## 5. 不要生成

- 默认勾选并自动执行；
- “加入团队”“设为主角色”；
- 角色之间的上下级关系；
- 超过三个选项的复杂菜单。
