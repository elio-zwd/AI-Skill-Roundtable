# Skill 角色详情全屏页候选

> 图片类型：完整二级页面
>
> 输出：1 张 1440 × 3200 Android 竖屏图片
>
> 目的：为【角色】一级页面中的角色详情提供全屏版本；对话内仍可保留大型详情 Bottom Sheet。

## 1. 背景与导航

遵循[共享视觉基线](../共享/jianyu-shared-visual-baseline.md)。本图从【角色】页打开“系统思考者”。

- 顶部左侧返回箭头；
- 标题：`Skill 角色详情`；
- 右侧收藏星标与更多菜单；
- 二级页面不显示底部一级导航；
- 系统返回与顶部返回都回到【角色】页原滚动位置。

## 2. Hero 区

大圆角浅薄荷渐变卡：

- 左侧大型半身人物肖像，与对话页系统思考者保持同一张脸；
- 右侧名称：`系统思考者`；
- 一句话定位：`从结构、关系与长期影响中发现关键问题`；
- 三个标签：`系统结构`、`因果关系`、`风险识别`；
- 若该角色最近使用过，显示弱灰文字 `最近使用：昨天`，不显示在线状态。

## 3. 详情内容

按纵向卡片组织：

1. `适合问 TA`
   - 复杂问题如何拆结构；
   - 哪些依赖会影响结果；
   - 长期风险在哪里。
2. `思维特点`
   - 从整体结构、反馈回路和边界条件分析。
3. `表达特点`
   - 先指出关键约束，再给出结构化判断和风险提醒。
4. `可能的局限`
   - 对需要快速直觉决策的问题，可能显得过于系统化。
5. `来源与时效`
   - 角色设定、资料来源和最近更新时间使用弱信息行展示。

每组左侧使用浅薄荷圆角 Icon Container，卡片白底、淡边框、大圆角。

## 4. 底部操作

固定在页面底部安全区上方：

- 主按钮：`开始新对话`，蓝紫渐变白字；
- 次按钮：`增加到当前会话`，紫色描边；
- 若没有可用当前会话，次按钮显示禁用态并写 `当前没有可加入的会话`，不得静默新建。

## 5. 真实人物型差异

本图使用虚构专业角色“系统思考者”，不显示真人声明。

后续为苏格拉底、史蒂夫·乔布斯出图时，在 Hero 说明下增加一行弱灰：

`AI 模拟角色，基于可获得资料构建，不代表本人。`

## 6. 不要生成

- 模型厂商 Logo、模型名称、Prompt 全文；
- 评分、下载量、排名；
- 主角色标记；
- 把“增加到当前会话”作为默认自动动作；
- 长篇法律免责声明压过人物信息。
