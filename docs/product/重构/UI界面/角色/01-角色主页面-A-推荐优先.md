# 【角色】主页面候选 A｜推荐优先

> 图片类型：完整一级页面候选图
>
> 输出：1 张 1440 × 3200 Android 竖屏图片
>
> 目的：判断“先给明确推荐，再提供完整目录”是否最适合新用户。

## 1. 必须继承

严格匹配[共享视觉基线](../共享/jianyu-shared-visual-baseline.md)：近白冷紫灰背景、轻描边大圆角卡片、蓝紫主色、人物化头像、Xiaomi 14 Ultra 中央挖孔。

底部导航为“对话 / 角色 / 资料 / 我的”，当前【角色】蓝色选中。

## 2. 当前页面状态

- 用户已使用过“规划教练”和“系统思考者”；
- 收藏了“研究员”；
- 系统推荐“产品顾问”“苏格拉底”“史蒂夫·乔布斯”；
- 当前没有打开具体会话，不显示“已加入当前会话”状态。

## 3. 页面布局

### 顶部栏

- 大标题：`Skill 角色`
- 一行副标题：`和不同的思考方式对话`
- 右侧：搜索图标、筛选图标
- 下方紧接全宽圆角搜索框：`搜索 Skill 角色`

### 推荐 Hero

区块标题：`为你推荐`

使用一张横向大卡片突出“研究员”：

- 左侧约 38% 为写实女性研究员半身肖像；
- 右侧为姓名、定位和两行说明；
- 说明：`从资料与证据出发，帮你核查事实、补齐信息缺口。`
- 三个弱标签：`资料核查`、`研究`、`来源判断`
- 右下紫色描边按钮：`查看角色`
- 背景为极浅蓝紫渐变，不能高饱和。

Hero 下横向排列两张较小推荐卡：

- 产品顾问；
- 苏格拉底，姓名下增加弱灰 `AI 模拟角色`。

### 最近使用

标题：`最近使用`，右侧文字按钮：`查看全部`

横向两张紧凑卡：

- 规划教练；
- 系统思考者。

每张卡包含人物头像、姓名、一行能力说明和最近使用时间，不显示“增加”按钮。

### 全部角色

标题：`全部角色`

单列列表显示至少 4 行：

- 研究员；
- 产品顾问；
- 苏格拉底；
- 史蒂夫·乔布斯。

列表行包含圆形头像、姓名、两行说明、收藏星标和右侧 Chevron。收藏的研究员星标为紫色实心。

## 4. 视觉重点

- 推荐 Hero 是页面第一视觉焦点，但高度不能超过首屏 28%；
- 人物肖像气质与对话页角色卡一致；
- 推荐理由要具体，不显示算法分数、热度榜或排名；
- 真实人物型角色只显示一处轻量 `AI 模拟角色`，不在主页面重复大段免责声明；
- 页面滚动内容延伸到底部导航上方。

## 5. 不要生成

- App Store 式价格、下载量、评分星级；
- “热门 Agent”“智能体市场”；
- 主角色、队长、排名第一；
- 自动加入当前会话的开关；
- 玻璃拟态或深色科技背景。

## 6. 用户主要比较点

- 推荐大卡是否抢占过多空间；
- 最近使用是否足够易达；
- 单列全部角色是否过长；
- 新用户能否快速理解每个角色的思维差异。
