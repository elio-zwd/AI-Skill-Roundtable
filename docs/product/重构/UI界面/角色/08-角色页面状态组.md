# 【角色】页面状态组候选

> 图片类型：同页面多状态对比
>
> 输出：优先生成 4 张独立图片；若工具受限，可生成 1 张四分栏状态板

## 1. 共享布局

以主页面候选 B“分类目录”为基础，遵循[共享视觉基线](../共享/jianyu-shared-visual-baseline.md)。底部【角色】选中。

## 2. 状态一：正常内容

- 分类 Chip 和 6 个角色双列卡；
- 研究员已收藏；
- 页面可正常滚动。

## 3. 状态二：收藏为空

- 当前切换到 `收藏`；
- 中央使用极淡紫色的线性星标插图；
- 标题：`还没有收藏的 Skill 角色`
- 说明：`收藏后，可以更快找到适合你的思考方式。`
- 按钮：`浏览全部角色`
- 不使用悲伤人物插画。

## 4. 状态三：搜索无结果

- 搜索词：`不存在的角色`
- 标题：`没有找到匹配的角色`
- 说明：`试试角色名称、能力或你想解决的问题。`
- 操作：`清除筛选`
- 保留搜索框和已选条件，让用户知道为何无结果。

## 5. 状态四：加载失败

- 保留顶部栏与搜索框；
- 中央白色弱描边状态卡；
- 标题：`角色暂时无法加载`
- 说明：`请检查网络后重试。已收藏和最近使用的本地记录不会因此删除。`
- 主按钮：`重试`
- 次入口：`查看最近使用`
- 不显示堆栈、HTTP 状态码或内部错误。

## 6. 比较重点

- 四个状态是否仍像同一个页面；
- 空状态是否简洁而不幼稚；
- 错误状态是否清楚但不过度恐吓；
- 操作按钮是否符合蓝主、紫辅的视觉规则。
