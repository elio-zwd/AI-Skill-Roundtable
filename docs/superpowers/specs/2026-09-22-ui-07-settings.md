# UI-07：模型、应用设置与关于

## 目标

收口“我的”页和设置页中剩余的可用性空洞：模型与 BYOK Key 继续使用已有 `AiManager`；设置页提供真正持久化的外观、无障碍和对话偏好；关于页说明见域身份、版本和 AI 模拟角色边界。

## 约束

- 不在界面、日志、导出或关于页显示完整 API Key；供应商和模型状态以 `AiManager` 的实际配置为准。
- 设置值使用独立的应用偏好存储，默认跟随系统；未实现的工程参数不暴露给用户。
- “显示敏感资料发送提醒”只控制额外提醒文案；敏感资料/个人背景的逐次发送确认属于不可关闭的请求级隐私门禁。
- 关于页不声称真人授权、准确复现或云端同步，不展示旧包迁移承诺。
- 模型选择保持已有 `AiManagementRoute` 的真实能力，不另建第二个 Key 池。

## 页面

- 设置页支持主题、字号/内容密度、减少动效、文字对比度、显示时间和敏感资料额外提醒等用户级选项。
- 关于见域作为二级页可从“我的”进入，显示 `com.elio.jianyu`、版本、许可证和 AI 模拟角色声明。
- 现有模型与 API Key 页保留，并补齐帮助说明和无 Key 状态，不伪造可用模型。

## 验证

- 偏好读写纯逻辑测试；Compose 覆盖开关修改、返回和关于声明。
- 运行 `compileDebugKotlin`、`testDebugUnitTest`、`lintDebug`、`assembleDebug` 和 `assembleDebugAndroidTest`。
