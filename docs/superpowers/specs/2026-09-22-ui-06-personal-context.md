# UI-06：个人背景可维护与会话授权

## 目标

把“我的”页中原本不可用的个人背景入口接成真实的本地能力：用户可以查看、添加、编辑、停用和删除自己主动保存的背景；背景默认不发送给任何 Skill 角色，只有在对话的上下文确认流程中明确选择后才会写入本次执行快照。

## 约束

- 使用 `JianyuRepository` 的 `PersonalContext` 读写接口，不新增第二套长期记忆存储。
- 列表只展示标题、脱敏摘要、敏感标签、生命周期和更新时间，不在“我的”首页泄露正文。
- 删除必须先经过确认；停用保留历史使用快照，不能抹掉既有成果来源。
- 保存、编辑和删除失败时保留用户输入并展示可恢复错误，不用 Toast 冒充成功。
- 继续复用已有 `ContextConfirmationDialog`，不自动把个人背景加入所有对话或所有角色。

## 页面

- `Mine` 个人背景卡显示真实数量并可打开 `个人背景` 二级页。
- 二级页提供搜索、全部/敏感/已停用筛选、列表和“添加个人背景”。
- 编辑表单要求标题和正文；敏感开关明确提示下次使用需要再次确认。
- 删除对话框要求输入“删除”，确认后调用生命周期接口，异常时不丢失条目。

## 验证

- ViewModel/纯逻辑覆盖搜索、保存、冲突和删除确认。
- Compose 覆盖空态、添加、编辑、敏感标记、停用和删除确认。
- 运行 `compileDebugKotlin`、`testDebugUnitTest`、`lintDebug`、`assembleDebug` 和 `assembleDebugAndroidTest`。
