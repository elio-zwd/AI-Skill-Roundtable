# UI-02 Skill 角色页面 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将已审查的 UI-02 规格实现为真实的 Skill 角色一级页面：`全部` 使用“推荐角色 + 最近使用 + 全部角色”布局，具体分类使用“分类说明 + 双列角色目录”，并完成全屏角色详情、开始新对话与增加到当前会话的真实链路。

**Architecture:** 保留 `OfficialSkillCatalog` 作为 Skill 能力/治理事实源，保留 Room `Character` 作为当前可对话角色的姓名、头像、tagline 与可用性事实；新增一个极小的角色发现分类清单，只承载 `Character.id -> primaryDiscoveryCategory`。`skills/` Route 负责把 Character、官方 Skill、收藏/最近状态投影为不可变角色页 UiState；Screen/Components 只渲染和发事件。角色页的“推荐角色”只取固定 `recommendable` 角色集合并按 `Character.order` 稳定排序，不做个性化推断。

**Tech Stack:** Kotlin、Jetpack Compose、Material 3、Room（沿用现有 Character 数据，不新增表）、kotlinx.serialization、JUnit、AndroidX Compose UI Test、Gradle Wrapper / JDK 17。

**Spec:** `docs/product/重构/UI界面/实施规格/UI-02/角色主页面-双布局-实施规格.md`

## Global Constraints

- 产品术语遵守 ADR-009 与 `docs/product/jianyu-terminology.md`：用户看到的是 **Skill 角色**，多个角色平级，不出现主/副角色、默认正反方或自动交叉讨论。
- UI-02 当前推荐区是固定可推荐集合，标题必须为 **`推荐角色`**；不得出现 **`为你推荐`**，不得把 `defaultOrder`、固定配置或 `recommendable=true` 表述成个性化匹配。
- 一级导航目标是 `对话 / 角色 / 资料 / 我的`；UI-02 不创建页面私有 Bottom Navigation，也不与 UI-01 并行复制一套导航。最终集成前必须基于已经落地的共享四项导航基线重新读取 `App.kt` 与 `ui/navigation/`。
- `全部` 状态采用 A 的信息层级；具体分类采用 B 的分类说明 + 双列目录；两者共用同一个标题区、搜索框、分类 Chip 与纵向滚动容器。
- 角色分类固定为：`思考方法 / 职业成长 / 研究学习 / 产品创造 / 沟通表达`；分类来自独立角色发现事实源，不从 `primaryType`、`primaryValue`、domain/scenario tags 临时推导。
- 生产角色身份来自真实 `Character` 数据；候选图中的“规划教练 / 系统思考者 / 研究员 / 产品顾问 / 苏格拉底”等仅是视觉样例，不能为了匹配图片而伪造生产角色。
- 真人型角色主卡只显示短标签 `AI 模拟角色`；完整声明来自官方 Skill `personDisclaimer` 或统一真人声明，放在详情/首次使用，不在列表铺长免责声明。
- 不新增 Room Schema、不升级 Kotlin/AGP/Compose/Room/Navigation 依赖；不修改网络、Gemini、TTS、备份协议。
- Route 收状态和副作用，Screen 接不可变 UiState 与事件，Components 只展示/局部交互；跨页面共享头像渲染必须放到 `ui/components/`。
- 所有点击目标至少 48dp；窄屏或大字体无法安全保持双列时允许降为单列。
- 选定 PNG 仍是视觉权威输入；本文和规格中的 dp/sp 是起始值，最终以 Xiaomi 14 Ultra 1440 × 3200 真实运行截图对比校准。
- 每个 Task 先写会失败的测试，再最小实现，再运行对应测试；不得通过删测试、弱化断言、吞异常制造通过。
