# Superpowers 项目开发工作流适配

本目录收录经过许可证审计的 Superpowers 6.2.0 必要工作流 Skill，并提供本项目的适配规则。它们是开发时参考资料，不是 Android 构建时依赖，也不会被 App 在运行时读取。

## 使用入口

- [项目工作流](project-workflow.md)：本项目的执行顺序、边界和人工降级规则。
- [Skill 映射](skill-mapping.md)：本地 6.2.0 全部 Skill 的审计结果、引入决定和适配要求。
- [上游记录](UPSTREAM.md)：来源、版本、许可证、引入范围和更新方式。
- [许可证](LICENSE)：Superpowers 上游 MIT License 原文。

## 引入范围

本次只引入 9 个开发工作流 Skill 的正文，以及它们被正文直接引用且对离线阅读有用的 Markdown 辅助资料。未引入插件清单、图标、代理配置、Shell/Node 脚本、视觉伴侣运行器、并行代理和 Worktree 辅助流程。

原文仍以英文保留，以避免把第三方内容误标为本项目原创；项目规则和审计说明使用中文。

## 维护边界

更新前必须重新核验上游版本、许可证、文件清单和敏感信息。任何更新都应保持来源记录，不把本目录当作自动同步的上游镜像。
