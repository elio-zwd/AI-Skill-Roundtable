# tools/device/AGENTS.md

本目录提供本地 AI 与自动化验收使用的 Android ADB 设备控制层。

## 规则

1. 所有设备动作必须绑定显式 Serial，或在恰好一台在线设备时解析唯一 Serial。
2. 多台设备在线且未指定目标时必须失败，不得静默选择第一台。
3. `adb` 命令返回零只表示命令已发送，不等于 UI 行为完成；交互动作应使用预期选择器验证。
4. 截图、UI XML、动作证据和日志必须写入仓库外目录。
5. 成功输出保持紧凑；失败只输出有限候选、有限 stderr 和证据路径。
6. 不在代码、测试或示例中硬编码用户个人路径、真实设备 Serial、密钥或隐私数据。
7. `pm clear`、卸载、重装等破坏性操作默认禁止；新增时必须要求显式授权参数。
8. 首版只使用 Python 标准库，不新增运行时第三方依赖。
9. 测试必须能在无 Android 设备的 Windows/Ubuntu CI 中运行。
10. 本目录不得修改 Android 生产行为；稳定 Compose `testTag` 属于后续独立 PR。

## 输出状态

- `PASS`：已通过明确状态断言；
- `FAIL`：命令、设备、选择器或预期状态失败；
- `NOT_VERIFIED`：动作已发送，但调用方没有提供可验证的预期状态。

不得把 `NOT_VERIFIED` 写成 `PASS`。
